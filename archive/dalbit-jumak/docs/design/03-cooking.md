# 03. 요리

## 1. 조리 시설

| 시설 | 방식 | 조리 시간 | 기본 보유 | 추가 구매 |
|---|---|---|---|---|
| 가마솥 | 미리 대량 조리. 한 솥 15그릇 (큰 가마솥 30그릇) | 새벽 준비 중에는 즉시, 영업 중 다시 끓이면 40초 | 1 | 15냥, 큰 가마솥 35냥 |
| 시루 | 미리 대량 조리. 한 시루 20개 | 같음 | 0 | 20냥 (평판 2) |
| 번철 | 주문 조리, 동시 1개 (넓은 번철 2개) | 레시피 CookSec | 1 | 12냥, 넓은 번철 30냥 |
| 화로 | 주문 조리 | 레시피 CookSec | 0 | 30냥 (평판 3) |
| 도마 | 주문 조리, 타지 않음 | 레시피 CookSec | 1 | 8냥 |
| 술독 | 숙성. 한 독에서 사발 단위로 따름 | 숙성 일수 | 술광 칸 수 | 술광 확장 |
| 장독 | 숙성. 장 1독 = 40회분 | 계절 단위 | 장독대 칸 수 | 장독대 확장 |

- 조리 시설은 부엌 칸을 차지한다. 부엌 단계별 3 / 5 / 7칸. 술독과 장독은 부엌 칸을 쓰지 않는다
- 시설 수치 기준: facilities.csv

## 2. 레시피

- 레시피 데이터: recipes.csv. 열 설명:

| 열 | 의미 |
|---|---|
| Station | 조리 시설 |
| Ingredients | 재료:수량 목록. 조리 1회분 |
| PriceFun | 판매가 |
| CookSec | 주문 조리 시간 (대량 조리 시설은 0) |
| BurnWindowSec | 완성 후 타기 전까지 시간 (0이면 타지 않음) |
| BaseQuality | 기본 품질 |
| UsesJang | 장을 쓰는 요리. 장 품질 보정을 받음 |
| Meat / Alcohol | 스님 금기 판정 |
| Takeout | 포장 가능 |
| Season | 팔 수 있는 계절 |
| Unlock | 해금 조건 |

- 해금 조건 값: start(시작), rep2~rep4(평판 단계), market_merchant(장터 상인 이야기), regular_story(단골 이야기 보상), festival(명절 행사), special_guest(특별 손님 보상), night_open(밤 영업 해금)

### 2.1 차림표
- 새벽 준비에서 오늘 팔 메뉴를 고른다. 기본 4개, 부엌 단계마다 +2
- 손님은 차림표 안에서만 주문한다. 선호 분류가 차림표에 없으면 보통 취향 메뉴를 고른다

### 2.2 대량 조리 규칙
- 새벽 준비에서 끓인 솥은 재료값을 미리 낸다
- 영업이 끝나면 남은 그릇은 버린다. 정산 화면에 "남은 음식" 손실로 표시
- 장부에 지난 7일 평균 판매량을 보여 줘서 솥 크기 판단을 돕는다

## 3. 품질

```
품질 = BaseQuality
     + 신선도 보정   (재료 중 가장 나쁜 상태 기준: 신선 +1 / 보통 0 / 시듦 −1)
     + 장 보정       (UsesJang 요리만: 장터 장 0 / 1계절 숙성 +1 / 2계절 이상 +2)
     + 솜씨 보정     (찬모 솜씨 4 이상 +1. 플레이어 직접 조리는 0)
     − 탄 음식 2
범위: 1 ~ 5
```

술의 품질은 숙성 곡선으로만 정한다 (4절).

## 4. 숙성

### 4.1 술
| 술 | 마실 수 있음 | 최고 품질 | 쉬기 시작 | 한 독 |
|---|---|---|---|---|
| 막걸리 | 2일 | 4일 | 8일 | 30사발 |
| 동동주 | 3일 | 6일 | 12일 | 30사발 |
| 약주 | 7일 | 14일 | 30일 | 20사발 |
| 소주 | 10일 | 20일 | 쉬지 않음 | 20사발 |

```
숙성일 < 마실 수 있음        : 따를 수 없음
마실 수 있음 ~ 최고 품질     : 품질 2 → 5 선형 증가 (반올림)
최고 품질 ~ 쉬기 시작        : 품질 5 유지
쉬기 시작 이후              : 품질 1 (쉰 술). 버리기 권장 알림
```
- 술도가 일꾼이 있으면 품질 +1 (상한 5)
- 기준 데이터: drinks_aging.csv

### 4.2 장
- 된장, 간장, 고추장. 장독대에서 담근다. 담그는 비용은 장 종류별 재료 1회분 × 40의 30% `[조정]`
- 담근 날로부터 1계절(10일)이 지나면 장 보정 +1, 2계절이 지나면 +2. 이후 유지
- 장이 떨어지면 장터 장(보정 0)을 자동으로 쓴다
- 봄에 담근 장은 숙성이 하루 빠르다 (정월장 관습을 단순화한 보너스) `[조정]`

## 5. 재료와 신선도

- 재료 데이터: ingredients.csv. 장터에서 산다
- 신선도 단계: 산 날 ~ 수명의 1/3 신선, 2/3까지 보통, 그 뒤 마지막 날까지 시듦, 수명이 지나면 상함(자동 폐기)
- FreshDays 0은 상하지 않음 (장류)
- 계절 재료(Seasons)는 그 계절에만 장터에 나온다
- 텃밭: 채소 일부를 자급. 단계별 30% / 60%만큼 채소 구매비 감소

## 6. 장터

| 항목 | 규칙 |
