## 1. 봇과 시험 방법

`./Tests/run.sh <판 수> [base|tree|modes|chips …]` (규칙 코어 `Tests/core_test.cpp`, 언리얼 없이 돈다). 전체 시험은 봇 때문에 20분 넘게 걸리고, `./Tests/run.sh 0` 은 단위 시험만.

| 명령 | 하는 일 |
|---|---|
| `run.sh 10` | 아래 봇 7종을 무한 곡선에서 10판씩, 무너진 웨이브 평균 |
| `run.sh 10 base` | 합성 + 조커 봇만 |
| `run.sh 10 tree` | 합성 + 조커 / + 트리 / + 트리 + 강화 |
| `run.sh N modes` | 30 · 60 · 100 모드 클리어율 (트리 봇, 영구 강화 0 / 8종 10레벨) |
| `run.sh N chips <모드 0~3> <강화 레벨> <해금 0/1/2>` | 판당 칩 (D-322) |

| 봇 | 하는 일 |
|---|---|
| 족보 무시 | 족보를 생각하지 않고 놓음 (바닥선) |
| 보상 안 받음 | 족보는 생각, 부적 · 보상을 안 고름 |
| 족보 생각 · 부적 먼저 | 판 위력이 가장 오르는 칸에 놓고 부적을 고름 |
| + 합성 | 위력이 오르는 족보를 바로 합성 |
| + 합성 + 조커 | 조커로 합치면 위력이 오르는 묶음을 먼저 조커로, 그다음 합성. 먹이기 포함 (D-098 뒤) |
| + 트리 | 골드(지금은 경험치 레벨)마다 위력이 가장 오르는 노드를 찍음 |
| + 트리 + 강화 | 강화까지 (D-230 뒤로는 영구 강화) |

봇의 한계 (숫자를 읽을 때 같이 볼 것)
- **레시피를 노리지 않는다**: 우연히 맞는 조커만 만든다. 만드는 조커는 거의 할리퀸(플러시 ×2) · 잭. 스타 · 광대 · 모자 장수 같은 상위 등급 조커는 거의 안 나온다
- **조커를 맞닿게 두지 않고, 먹이기를 한 조커에 몰아 준다** → 상위 조커 0개 (D-235, D-332)
- 손패를 아끼지 않고 웨이브를 바로 넘긴다 (자동 시작 대기 · 초반 12초는 숫자에 안 나옴)
- 판 위력을 15%까지 깎으며 먹인다 → 조커 재료를 먹이로 써 버려 먹이기 봇이 오히려 낮게 나온 적이 있다 (D-098)
- 판 위력 어림은 사거리 · 적 위치를 거의 안 본다 (트리 봇만 사거리 안 길 칸 수로 가중)
