# 32. 만능 제거 유지 + 모드 체력 재조정 vs D-489 되돌리기 (기획안)

작성: 2026-11-27, 기획 (이슈 #27 이어서)
상태: **임씨 결정 대기**. 추천 = **1안: 만능 제거 유지 + 모드 체력 재조정**
근거: [QA 31](31-qa-joker-bonus-d491.md) (덤 갈래 430판), [QA 29](29-qa-joker-not-wild-d489-d490.md). 앞 기획 [27](27-joker-not-wild.md) · [30](30-joker-power-after-d489.md)

## 1. 지금 알게 된 것

- 예전 조커는 와일드로 **족보 평균 4.3개에 동시에 들어**, 그 효과를 **모두 곱으로** 받았다. 조커 공격력 ×83 · 연사 ×2.25 · 범위 덤, 판 위력이 지금의 **약 200배**
- 그 눈덩이 덕에 판 위력이 웨이브마다 **×1.5** 로 올랐고, 30 모드 적 체력 증가(×1.9, D-235)도 그 속도에 맞춰 올린 값이다
- 지금 조커는 먹이기 · 합치기로만 커져 웨이브마다 **×1.15**. 덤은 곡선을 위로 올릴 뿐 기울기를 못 바꿔, **덤 하나로는 어떤 값도 안 맞는다** (30 모드를 깨려면 덤 300)
- **덤과 체력 증가를 같이 낮추면 돌아온다**: 30 모드 체력 증가 1.9 → **1.45** + 덤 **10** = 10판 중 6판 (60%)
- 와일드 계산이 빨라져서 D-489 를 되돌려도 성능 문제는 없다 (판당 70 ~ 263초 → 8 ~ 20초)

임씨가 처음 짚은 "조커가 족보 능력치까지 받는 건 불합리" 는 숫자로 보면 더 컸다. 1.2배 덤이 아니라 **눈에 안 보이는 200배 곱**이었다.

## 2. 두 안

| | **1안. 만능 제거 유지 + 모드 체력 재조정 (추천)** | 2안. D-489 되돌리기 |
|---|---|---|
| 규칙 | "조커는 족보에 안 든다" 그대로. 바뀌는 건 숫자: 조커 덤 3 → 약 10, 모드별 체력 증가율 | 조커 = 와일드 (아무 숫자 · 무늬 · 레벨), 낀 족보 합성 불가, 먹이기 우선순위, 파이브 카드 조건 등 예외 규칙이 돌아옴 |
| 임씨 의도: 심플한 규칙 | **맞음** | 어긋남 |
| 임씨 의도: 족보 효과를 두 번 받지 않기 | **맞음** | 어긋남 (곱으로 평균 4.3번) |
| 플레이어가 보는 힘 | 조커 숫자 · 레벨 · 먹이기로 보임 | 판 위 족보 배치에 따라 숨은 곱으로 수십 배씩 흔들림 |
| 밸런스 일 | **큼**: 덤을 정하고 30 · 60 · 100 · 무한 체력 증가율을 새로 맞춤. 판이 빨라져(434판 약 25분) 하루 안에 몇 바퀴 가능 | 작음: D-489 전 밸런스로 돌아감. 다만 30 모드 80% · 100 모드가 60 모드보다 쉬움은 원래 남은 숙제 |
| 손에 남는 것 | 성장 곡선이 덜 가팔라 (웨이브당 ×1.15) 후반 "판이 폭발하는 맛" 이 줄 수 있음 → 먹이기 성장 · 상위 조커 쪽에서 되살릴 여지 | 눈덩이 재미는 그대로, 대신 카드 배치 하나가 수십 배를 좌우 |
| 이미 한 일 | D-489 · D-490 · D-491 구현을 그대로 씀 | D-489 · D-491 코드를 되돌리고, D-490 (모자 장수 · 스타 · 할리퀸) 은 만능 기준으로 다시 재야 함 |
| 성능 | 문제 없음 | 문제 없음 (와일드 계산 개선 뒤) |

## 3. 추천: 1안

1. **임씨가 정한 방향 두 가지를 다 지킨다.** 2안은 성능이라는 이유가 사라졌을 뿐, 처음 불합리하다고 본 것(이중 혜택)과 복잡한 예외는 그대로 돌아온다. QA 31 로 그 이중 혜택이 ×200 이었다는 게 드러났으니, 되돌릴 이유보다 유지할 이유가 더 커졌다
2. **남은 건 숫자 일이다.** 체력 증가율은 원래 "만능 조커 판에 맞춘 임시값" (D-235) 이었고, 어느 안이든 30 · 100 모드 재조정은 남아 있었다. 1안은 그걸 지금 한 번에 한다
3. **위험**: 밸런스가 맞기까지 며칠, 그동안 main 은 플레이 테스트용으로 쓰기 어렵다. 후반 성장감이 약하면 먹이기 흡수(60%) · 레벨당 위력(+50%) 쪽을 다음 손잡이로 쓴다 (덤처럼 판 전체를 올리는 대신 키우는 행동에 보상)

### 1안의 내용

| 항목 | 값 |
|---|---|
| 조커 덤 (`JokerBonus`) | 3.0 → **10** (시작값, QA 31 5절) |
| 30 모드 15웨이브 뒤 체력 증가 (`ModeGrowth`) | 1.9 → **1.45** (15웨이브 전과 같게) |
| 60 · 100 · 무한 | 1.37 · 1.2 · 1.3 → QA 가 덤 10 기준으로 맞춤. 목표: 60 모드 30 ~ 40%, 100 모드 25 ~ 35% (60 보다 어렵게), 무한은 기록 |
| 30 모드 목표 | 60 ~ 75%, **40판**으로 확인 (지금 6/10 은 범위가 넓음) |
| 개발 | 덤 · 체력 증가율을 봇 인자로 받게 (QA 31 권고 3), 와일드 카드 덩어리 계산 |
| 그 뒤 | 모자 장수 행운 확률(QA 29), 카드 타워 몫(판 위력의 98 ~ 100% 가 조커) 검토 |

## 4. 고른 뒤

- 1안: ADR D-492 (D-491 보완: 덤 10 + 모드 체력 증가율 재조정, D-235 대체), 개발 → QA 전 모드
- 2안: ADR D-492 (D-489 · D-491 폐기, 시작 자리바꿈 2번은 남길지 따로), 개발 되돌리기 → QA 로 D-490 다시
