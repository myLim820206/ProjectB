# 36. 먹이기: 판 아무 족보나 먹이고, 모든 조커가 경험치를 받는다 (D-494)

작성: 2026-11-28, 기획 (임씨 지시, 이슈 #50)
배경: [QA 35](35-qa-joker-spec-before-leveling.md) — 먹이기가 한두 마리에 몰리고 판 위 조커 평균 레벨은 30웨이브에도 5.7

## 결정 요약

| 항목 | 지금 (D-098 · D-213 · D-489) | 바뀜 |
|---|---|---|
| 먹일 수 있는 족보 | 조커에 맞닿은 족보만 | **판 위 아무 족보나.** 조커가 판에 한 마리라도 있으면 된다 |
| 먹는 조커 | 고른 조커, 안 골랐으면 맞닿은 조커 중 레벨 높은 쪽 | **판 위 모든 조커.** 고르는 단계가 없다 |
| 조커 한 마리가 받는 경험치 | 족보 점수 × 먹인 타워 평균 위력 | **같은 양을 조커마다 다 받는다** (나누지 않음) |
| 위력 흡수 | 먹인 타워 세기의 60% 를 그 조커에 | **조커마다 60%** (각자 자기 단위로 바꿔서) |
| 먹보 (+50% 경험치) · 먹이 사슬 (흡수 90%) 부적 | 먹은 조커에 | 조커마다 |
| 처치 경험치 (처치 +1, 보스 +15) | 처치한 조커만 | **그대로** |
| 새로 만든 조커 | 레벨 1 | 그대로 레벨 1 (이후 먹이기부터 같이 받음) |
| 같은 조커 합치기 · 상위 조커 | 레벨은 높은 쪽 | 그대로 |

한 줄로: **"족보를 먹이면 판 위 조커 전부가 그만큼 큰다."**

## 1. '효율은 지금과 같게' 를 어떻게 읽었나

두 가지로 읽힌다. 시제(아래 3절)로 둘 다 돌려 봤다.

| | (a) 조커마다 지금만큼 (고름) | (b) 지금 양을 나눔 |
|---|---|---|
| 뜻 | 먹이 하나가 지금 한 마리를 키우던 만큼 모든 조커를 키운다 | 먹이 하나가 주는 총 경험치는 지금과 같고, 조커 수로 나눈다 |
| 플레이어 말로 | "먹이면 다 같이 큰다" | "먹이면 다 같이 조금씩 큰다" |
| 판 위력 (60 모드, 10 · 20웨이브 중앙) | **+25% · +29%** | +25% · −3% |
| 무너진 웨이브 (60 모드, 어렵게 1.20) | 평균 **+1.6웨이브** | −0.3웨이브 |
| 조커 평균 레벨 30웨이브 | 5.7 → **8.2** | 5.7 → 6.6 |
| 문제 | 판이 조금 세짐 → 체력 증가율 재확인 | 조커가 많을수록 먹이기 한 번이 약해 보여 "먹여도 안 오른다" 는 느낌. 조커를 더 만들면 손해 보는 이상한 구조 |

**(a) 를 고른다.** 임씨 말("모든 조커의 경험치를 먹게")에 가장 가깝고, 걱정했던 위력 폭증이 없다 (3절). 늘어난 25% 는 모드 체력 증가율로 바로 맞출 수 있는 크기다 (60 모드 증가율 1.165 기준 약 1.5웨이브).

흡수까지 조커마다 60% 로 둔 이유: "경험치는 각자, 흡수는 나눔" 은 규칙이 두 줄이 된다. 시제에서 흡수를 나누든 각자 주든 판 위력 차이가 1% 도 안 됐다 (조커 위력은 덤 10 · 등급이 대부분이라 흡수 몫이 작다). 그래서 둘 다 "조커마다 지금만큼" 으로 하나로 맞춘다.

## 2. 왜 생각보다 안 세지나 (레벨링 테스트에 중요)

- **가장 높은 조커 레벨은 거의 안 변했다** (60 모드 중앙 35 → 33.5 ~ 37.5). 레벨 30 대까지 가는 경험치(약 5,000 ~ 6,000)의 대부분이 **처치 경험치**에서 나오기 때문이다. 판당 먹이기는 지금 11번, 먹이 한 번 경험치는 20 ~ 120 이라 다 합쳐도 수백 ~ 1,000 정도 (어림)
- 즉 QA 35 의 "레벨이 한 마리에 몰린다" 의 주원인은 먹이기가 아니라 **가장 센 조커가 가장 많이 잡아서 더 커지는 처치 눈덩이**다. 이번 변경은 평균 레벨(5.7 → 8.2)을 올려 나머지 조커를 쓸 만하게 하지만, 최고 레벨 쏠림은 그대로 남는다
- 그래서 레벨링 테스트(QA 35 6절)의 L1 상한 · L2 레벨당 위력 · L3 곡선은 여전히 필요하고, 처치 경험치를 판 전체로 나누는 갈래(L5)를 새로 더 볼 만하다 (5절)

- 판당 먹이기가 두 배(11 → 23)가 됐다. 어디서나 먹일 수 있어 먹일 거리가 늘었다. 봇은 판 위력을 깎는 먹이기는 안 하니, 사람도 비슷하게 "남는 족보를 먹이로" 쓰게 될 것

## 4. 화면 · 조작

먹일 조커를 고르는 단계가 없어지니 D-213 먹이기 목록과 칸 메뉴(D-313)를 줄인다.

| 자리 | 지금 | 바뀜 |
|---|---|---|
| 왼쪽 목록 **먹이기** 줄 | 누르면 조커 목록 → 조커 고르기 → 족보 클릭 | 누르면 **먹이기 모드**: 먹일 수 있는 족보 전부가 분홍 덩어리, 족보 칸 클릭 = 먹이기. 조커 목록 · 조커 고르기 없음. 줄 글자 "먹이 ×N" 그대로 (N = 판 위 족보 수, 조커가 없으면 줄이 흐림) |
| 칸 메뉴 (타워 클릭) | **조커** 메뉴에 "맞닿은 족보 먹이기" 줄들 | **족보 타워** 메뉴에 "먹이기" 한 줄 (그 타워가 든 족보, 여럿이면 족보마다). 조커 메뉴에선 먹이기 줄을 뺀다 |
| 전후 툴팁 | 레벨 · 경험치 · 조커 위력 · 판 위력 · 사라지는 카드 수 | "조커 N마리 경험치 +X", 레벨이 오르는 조커 수 ("레벨 업 2마리"), 판 위력 전후, 사라지는 카드 수. 판에서 레벨이 오를 조커 머리 위에 작은 ▲ |
| 먹이기 연출 (D-315 · Fx) | 먹인 칸 → 그 조커로 빨려 드는 입자 | 먹인 칸에서 **모든 조커로** 입자가 갈라져 날아감. 레벨이 오른 조커만 고리. 조커가 많으면 입자 수를 조커 수로 나눔 |
| 판 위 분홍 점 (D-113) | 조커에 맞닿은 족보에 | 판 위 거의 모든 족보에 찍혀 시끄러워지므로 **먹이기 점은 뺀다**. 먹이기는 목록 줄 · 칸 메뉴로 |
| 도움말 카드 '먹이기' | 맞닿은 족보 설명 | "족보를 먹이면 판 위 모든 조커가 경험치를 받아요" |
| 용어집 · 도감 · 조커 메뉴 설명 | "맞닿은 족보를 먹여" | "판 위 족보를 먹여 모든 조커를 키운다" |

글자는 모두 언어팩을 거친다 (D-159).

## 6. 대안

- (b) 나눔: 총량은 같지만 조커를 더 만들수록 먹이기가 약해져 "조커를 만들면 손해" 가 된다. 위력도 지금과 같아 쏠림만 남음
- 판 공용 레벨 하나 (모든 조커가 같은 레벨, 처치 경험치도 공용): 가장 단순하지만 처치 · 합치기 · 상위 조커 레벨 규칙까지 바뀌는 더 큰 변경. 레벨링 테스트 L5 결과를 보고 다시 판단
- 경험치는 모두에게, 흡수는 그대로 한 마리만: 흡수 받을 조커를 고르는 단계가 다시 필요해 간소화 목적에 어긋남
