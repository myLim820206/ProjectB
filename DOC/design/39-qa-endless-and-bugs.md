## 2. 조합 · 먹이기 불변식 검사 (봇에 검사기를 붙여서)

봇이 쓰는 함수(`Feed` · `JokerCraft` · `JokerFuse` · `MergeJokers`)를 감싸 매번 앞뒤 판을 비교하고, 정리 단계마다 판 전체를 검사했다. 검사기 [Tests/qa/qacheck.h](../../Tests/qa/qacheck.h), 붙이는 패치 [Tests/qa/core_test-qacheck.patch](../../Tests/qa/core_test-qacheck.patch).

| 검사 | 확인한 것 |
|---|---|
| 정리 단계마다 | 칸 키 = X · Y, 위력 배율 유한 · 양수, 조커 레벨 ≥ 1, 0 ≤ 경험치 < 다음 레벨, 조커 종류 올바름, 족보 칸에 조커 없음, 먹이기 · 합치기 목록 번호 · 칸이 올바름, 상위 조커 짝이 레시피와 맞음 |
| 먹이기 | 먹인 칸만 사라짐, 모든 조커가 같은 경험치 전량 (먹보 ×1.5), 조커마다 흡수 = `FeedGain`, 조커가 사라지지 않음 |
| 조커 만들기 | 레시피와 재료 족보가 정확히 맞음, 잠긴 조커 아님, 조커 칸을 재료로 안 씀, 위력 = 재료 합 × 배율 × 등급 × (1 + 0.1 × 카드 수), 새 조커 레벨 1 · 경험치 0, 재료 칸 안에 놓임, 다른 조커는 그대로 |
| 합치기 | 레벨 = 높은 쪽, 같은 조커 위력 = 합 × 1.3, 상위 위력 = 합 × 1.5 / 1.3 (왕관 2.2) × 트리 덤, 상위 종류 · 부모 능력 둘 다 가짐 |

## 3. 버그 (재현 · 심각도)

### 버그 1. 바다코끼리와 목수가 ★ 대표 조커가 아님 — 중간 (#66)

- 기획: D-333 · [18 상위 조커](18-upper-jokers.md) "★ 대표 11종: 둘 다 조커 레벨 10, ×1.5". 바다코끼리와 목수가 11종에 들어 있다. 도감 글자도 "★ 대표 11종"
- 코드: `GPDUpper` 17번(희비극 + 지휘봉)이 `EPDUpperSpecial::None`. ★ 판정이 `Special != None` 이라 일반으로 처리 → **레벨 조건 없음, ×1.3**. 실제 ★ 은 10종, 일반 20종
- 까닭: D-331 때 바다코끼리 고유 능력은 부모(희비극 셋째 적 + 지휘봉 연사)로 이미 나와서 따로 값을 안 만들었는데, D-333 이 ★ 을 `Special` 로 가르면서 일반으로 떨어졌다
- 재현: 희비극 레벨 1 과 지휘봉 레벨 1 을 맞닿게 → 상위 합치기 목록에 뜨고, 합치면 위력 합 × 1.3
- 영향: 봇이 두 번째로 많이 만드는 상위 조커 (무한 1.18 22/40판, 60 모드 21/40판, 그 판에서 판 위력의 약 15%). 고치면 레벨 10 이 될 때까지 못 만들어 판이 조금 약해진다 → 체력 증가율 재측정 필요

### 버그 2. 처치 경험치 주인을 "쏜 칸" 으로 가림 — 낮음 (#67)

발사체는 쏜 타워의 칸 키(`Src`)만 들고 다니고, 닿을 때 그 칸에 지금 조커가 있는지로 판정한다. 웨이브 중에도 조커 만들기 · 합치기가 되므로 칸이 바뀔 수 있다. 사본 시험 [Tests/qa/qa_rules.cpp](../../Tests/qa/qa_rules.cpp):

| 경우 | 결과 | 기대 |
|---|---|---|
| A 카드 발사체가 잡음 (판 그대로) | 조커 경험치 0 | 0 ✓ |
| B 카드 발사체가 날아가는 동안 그 칸 카드로 조커를 만듦 | 판 위 조커 모두 +2/3 | 0 (카드가 잡음) ✗ |
| C 조커 발사체가 날아가는 동안 그 조커가 옆 칸 상위 조커 재료로 들어감 | 0 | +2/3 (조커가 잡음) ✗ |

양이 한 번에 2/3 라 밸런스 영향은 거의 없다. 안: 쏠 때 조커였는지를 발사체에 같이 담는다.

### 버그 3. 상위 조커 합치기에서 경험치가 사라짐 — 낮음, 기획 확인 (#67)

| 경우 | 결과 |
|---|---|
| D 상위 합치기: 레벨 6 (경험치 69/70) + 레벨 4 | 레벨 6, 경험치 **0** |
| E 같은 조커 합치기: 레벨 6 (10) + 레벨 6 (25) | 레벨 6, 경험치 25 (높은 쪽 이어받음) |

레벨은 높은 쪽을 잇는데 진행분만 버린다. 같은 조커 합치기와 맞추는 게 자연스럽다. 일부러 0 이면 이슈를 닫는다.

- 연쇄 폭발 부적으로 죽은 적은 터뜨린 타워의 처치로 셈: 같은 `HitSrc` 안이라 일관됨
