# 디자인 문서와 그림 규칙

모든 디자이너 작업은 같은 가이드를 따른다: **[15-art-style.md](15-art-style.md) (화풍, 필수)** 와 아래 그림 규칙.
문서용 시안 · 미리보기 그림은 `DOC/assets/images/` 에 둔다.

## 화풍 (요약)
웹 프로토타입 네온: 거의 검은 배경, 채우지 않은 한 색 가는 선, 넓고 부드러운 빛번짐, 판 위 물체는 둥근 사각 틀 안에 작은 기호. 인게임은 Alice 시안 색감 예외가 있다 (D-403, 자세한 것은 15-art-style.md).

## 그림 규칙 (모든 그림에 적용)
- **화면의 모든 그림은 스프라이트로 그린다** (D-146). 그림은 코드로 정의하고(바깥 이미지 파일 금지), 에디터 PIE 에서 F8 로 텍스처 에셋 `Content/Sprites/T_PDAtlas` 에 구워 찍어 쓴다. 그림 코드를 고치면 F8 을 다시 누르고 에셋을 커밋한다.
  - 정해진 물체(카드 · 조커 · 이펙트 모양 등)는 아틀라스 칸을 하나 만들어 찍는다. 새 그림을 넣으면 아틀라스 칸도 같이 추가한다.
  - 예외 (D-403): Alice 인게임 시안 그림에서 잘라 낸 바뀌지 않는 그림(야자수 · WAVE 간판, BAR Alice 로고, 칵테일 잔)은 `tools/ui_art/cut_ref.py` 가 `Content/UIArt/*.png` 로 만들고 게임이 실행 중에 읽는다. 숫자 · 글자처럼 바뀌는 것은 코드로 그린다.
  - 그 밖의 선은 `FCanvas::Lines` 가 아틀라스의 선 스프라이트를 늘여 찍는다 (직접 Slate 선을 그리지 않는다). 판 배경처럼 판마다 다른 것만 실행 중에 굽는다. 글자는 Slate 글꼴 텍스처.
- 나이아가라 · 머티리얼 에셋은 이펙트에만 쓰고, 화풍을 따른다. 월드 이펙트 층은 Slate 판 뒤에 그려진다 (D-092).
- 새 그림은 `tools/neon/neon.py` 로 먼저 미리보기를 그려 보여 주고 언리얼에 옮긴다.
