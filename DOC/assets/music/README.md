# 음악 만들기 (D-364)

Claude 가 리프 · 코드 · 베이스 · 드럼을 MIDI 로 뽑고 → 맥 GarageBand 에서 진짜 악기 소리를 입혀 → WAV 로 내보내 언리얼에 넣는다.

## 파일
- `last_call.mid` — 시험용 첫 곡. 직접 만든 곡, 84 BPM 느린 스윙, C 단조 8마디 반복. 트랙 4개: 선율 · 키(전자 피아노) · 업라이트 베이스 · 드럼
- 다시 뽑기: `python3 tools/music/make_midi.py`

## GarageBand (맥에 무료, 없으면 App Store)
1. 새 프로젝트 → 빈 프로젝트 → 소프트웨어 악기
2. Finder 에서 `.mid` 파일을 트랙 영역에 끌어다 놓기 → "템포 정보 가져오기" 물으면 예 → 트랙 4개가 생김
3. 트랙을 하나씩 고르고 왼쪽 라이브러리에서 악기 바꾸기
   - 선율: 비브라폰(Mallets 쪽) 또는 색소폰 · 플루트
   - 키: Electric Piano 쪽 (로즈 느낌)
   - 베이스: Upright / Acoustic Bass 쪽
   - 드럼: 처음엔 피아노 소리로 나올 수 있음 → Drum Kit 에서 재즈 · 브러시 느낌 킷
4. 마음에 안 드는 음은 피아노 롤에서 끌어서 고치고, 반복해서 곡 길이를 늘리기
5. 공유 → 노래를 디스크로 내보내기 → WAV (16비트, 44.1kHz)

반복 재생용이라 맨 끝 꼬리(잔향)가 처음으로 자연스럽게 이어지는지 들어 보기.
