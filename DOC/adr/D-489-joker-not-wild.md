# D-489. 조커는 족보에 안 들어간다 (만능 제거), 시작 자리바꿈 2번

- 날짜: 2026-11-27
- 상태: 확정
- 이슈: #27
- 대체: D-069 의 "조커는 맞닿은 족보에서 와일드", D-200 · D-207 의 "조커가 낀 족보는 합성 불가", D-213 의 "족보 안에 낀 조커가 먹는다", D-075 의 파이브 카드 조건 중 "조커"

## 결정
- 판 위 조커는 족보를 찾을 때 **없는 칸처럼** 친다 (숫자 · 무늬 · 레벨 만능 없음, 줄기를 끊음)
- 와일드 카드(보상)는 그대로 만능
- 그래서 없어지는 규칙: 조커가 낀 족보 합성 불가, 먹이기의 "족보 안에 낀 조커 먼저" (맞닿은 족보만 먹음), 파이브 카드의 "조커" 조건
- 조커 능력 · 대장 지휘 · 먹이기 · 같은 조커 합치기 · 상위 조커(맞닿기)는 그대로
- **새 판은 자리바꿈 2번으로 시작** (모든 모드, 보상 자리바꿈과 더해짐)
- 자세히: [27-joker-not-wild.md](../design/27-joker-not-wild.md)

## 이유
임씨: 조커 자체만으로도 강한데 족보 능력치까지 합쳐지면 안 될 것 같다. 1장만 만능은 룰이 더 복잡하니 심플하게. 자리바꿈 카드가 있으니 배치는 할 만하고, 초반에 자리바꿈 2개를 주고 시작하자.
QA(#25, 문서 26 문제 2): 조커 3개 이상이 맞닿으면 족보 계산 135 ~ 323ms. 만능을 빼면 원인째 사라진다.

## 대안
- 조커 1장만 만능: 룰이 복잡해짐 (임씨 기각)
- 만능은 두고 족보 배율만 조커에 안 붙이기: 숨은 계산, 성능 문제 그대로
- 그대로 두고 계산만 빠르게: 이중 혜택 · 예외 규칙이 남음
- 시작 자리바꿈 4번 (보상 두 장): 상위 조커 짝 맞추기까지 공짜가 되어 보상 자리바꿈 값이 떨어짐
