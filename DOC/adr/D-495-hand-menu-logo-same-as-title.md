# D-495. 족보 메뉴판 로고를 시작 화면 간판과 똑같이

- 날짜: 2026-11-28
- 상태: 확정
- 이슈: #53
- 대체: D-453 의 '높이 40 칸 · 인게임용 가는 관' (D-454 의 −8° 기울임은 그대로)

## 결정
- 인게임 왼쪽 위(족보 메뉴판 맨 위) BAR Alice 로고를 시작 화면 간판과 똑같이 그린다 (같은 `PaintAliceSign`). 기울기만 다르다: 시작 화면 0°, 인게임 −8° (D-454, 사용자: 메인 간판은 똑바로, 인게임은 기울이는 게 맞다)
- 관 선 1.5배 · 넓은 번짐(D-464 · D-465)을 시작 화면만이 아니라 늘 쓴다. 굵기는 너비에 비례하므로 작게 그려도 모양 비율이 같다
- 크기: 너비 100 (예전 83). 획이 그려지는 범위(원본 x 54 ~ 1075, y 65 ~ 465, 약 90 × 35)를 패널 안 (LX + 12, 19) 에 맞춘다 (기울이면 잔 불꽃이 위로 올라가 3 내림). '족보 메뉴' 제목(가운데 y 66)과 뒤로 버튼에 닿지 않는다
- 벽돌 벽 · 깜빡임은 시작 화면에만 (인게임은 모두 켜짐)
- 비교 그림: `DOC/assets/images/ingame-logo/logo_before_after.png` (파이썬 근사 미리보기)

## 이유
사용자: 메인 화면 간판이랑 인게임 왼쪽 위 그림이 비슷한데 같은 것으로 바꿔 달라. 획은 이미 같았지만 기울기 · 가는 관 · 작은 크기 때문에 다른 그림처럼 보였다.

## 대안
- 더 크게(너비 120 이상): '족보 메뉴' 제목과 겹쳐 제목을 내려야 하고, 아래 메뉴 줄이 모두 밀린다
- 인게임도 0°: 처음엔 이렇게 머지했지만(PR #54) 사용자가 인게임은 기울인 게 맞다고 해 되돌렸다 (PR 다음 판)
