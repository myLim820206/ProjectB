# D-484. 간판 마티니: 술 선은 한 줄, 빨대는 술 선 위에서 끝

- 날짜: 2026-11-27
- 상태: 확정
- 이슈: #13
- 대체: D-483 의 술 선 끊기 · 빨대 길이

## 결정
- 하늘색 술 선은 빨대 자리에서 끊지 않고 한 줄로 잇는다 (시안처럼). 높이는 윗변 아래 36 (원본 화소)
- 빨대는 윗변 틈을 지나 술 선에 닿기 직전(반폭 합 + 6)에서 끝난다. 윗변 위로 나온 길이 50 → 36
- 얼음은 술 선 아래 가운데 마름모 (반 대각선 15)

## 이유
사용자: 시안은 파란 일직선이 이어져 있다, 빨대는 파란 선 위로 올리고 길이를 조금 줄여 달라.

## 대안
- 빨대가 술 선을 지나가게: 선끼리 겹친다 (D-482)
