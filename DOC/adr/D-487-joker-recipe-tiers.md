# D-487. 조커 레시피를 하나로, 재료 수는 대장 족보의 뽑기 난이도로 (2 · 3 · 4개)

- 날짜: 2026-11-27
- 상태: 일부 대체 (D-490: 할리퀸 레시피, 모자 장수 · 스타 등급)
- 이슈: #19 (기획), #21 (구현)
- 대체: D-118 (3개 + 2개 레시피), D-116 (조커별 등급 배율), D-370 (조커 목록의 3개/2개 레시피 전환 표시)

## 결정
- 조커마다 레시피는 **하나** (3개 / 2개 OR 를 없앤다). 정확히 맞을 때만 조커 (개수가 다르면 다른 레시피)
- 재료 수 = 대장 족보의 뽑기 난이도. 흔함(원 페어 · 플러시 · 스트레이트 · 투 페어) 4개, 중간(트리플 · 풀하우스) 3개, 드묾(포카드 · 파이브 카드 · 스트레이트 플러시 · 로열) 2개
- 짝 재료는 흔한 족보(원 페어 · 플러시 · 스트레이트 · 투 페어)만, 스트레이트는 레시피에 최대 하나. 같은 족보를 여러 번 넣어도 된다 (재료는 판 어디서나 고름, D-195)

| 조커 | 재료 | 레시피 |
|---|---|---|
| 희비극 | 4 | 원 페어 + 원 페어 + 플러시 + 플러시 |
| 할리퀸 | 4 | 플러시 + 플러시 + 플러시 + 원 페어 |
| 지휘봉 | 4 | 스트레이트 + 원 페어 + 원 페어 + 플러시 |
| 웃는 가면 | 4 | 투 페어 + 원 페어 + 플러시 + 스트레이트 |
| 잭 | 3 | 트리플 + 원 페어 + 플러시 |
| 방울 | 3 | 풀하우스 + 플러시 + 스트레이트 |
| 체셔 | 2 | 포카드 + 플러시 |
| 광대 | 2 | 파이브 카드 + 원 페어 |
| 모자 장수 | 2 | 스트레이트 플러시 + 원 페어 |
| 스타 | 2 | 로열 스트레이트 플러시 + 원 페어 |

- 등급 배율은 재료 수로: 4개 ×1.6, 3개 ×2.5, 2개 ×3.5 (조커 위력 = 재료 위력 합 × 1.2 × 등급 × (1 + 0.1 × 재료 카드 수) 는 그대로)
- 자동 묶음(JokerGroups)은 재료가 많은 레시피 먼저, 같은 개수끼리는 낮은 족보부터, 칸이 겹치지 않게
- 화면: 조커 목록에서 고른 줄은 레시피 하나에 체크, 재료 번호 1~4, 도감 · 잠금 해제 책은 "재료 N · 족보…" 한 줄 (재료 4개는 알약 두 줄), 안내문은 "레시피의 족보를 모두 골라…" (언어팩)
- 모자 장수 · 스타는 이번엔 재료만 2개로. QA 레시피 노림 봇으로 다시 재서 판의 10% 미만이면 스트레이트 플러시를 4장부터 인정하는 안을 따로 올린다

## 이유
임씨: 도감이 3개 아니면 2개 OR 조건인데, 뽑기 난이도별로 2개 3개 최대 4개까지 조합하도록 바꾸자. 기획안 [25-joker-recipe-tiers.md](../design/25-joker-recipe-tiers.md) 의 추천을 그대로 채택.
QA(이슈 #5): 쉬운 조커 셋이 독식, 스트레이트를 먹는 지휘봉 · 잭 · 체셔는 레시피가 생겨도 안 만듦, OR 레시피 탓에 난이도가 대장 족보 하나로만 갈림.

## 대안
- 정식 레시피 + 하나 적은 레시피 두 개를 두고 개수만 2 · 3 · 4: 결국 짧은 쪽만 쓰여 재료 수로 난이도를 나눈 의미가 사라짐
- 조커별 등급 배율(D-116) 유지: 4개 레시피가 재료 · 카드 덤으로 25~40% 세져 쉬운 조커가 더 강해짐
