# D-500. 조커를 합치면 경험치는 0 부터 (레벨은 높은 쪽)

- 날짜: 2026-11-28
- 상태: 확정
- 이슈: #67 (QA 39 버그 3)

## 결정
- 상위 조커로 합치면 **레벨은 재료 중 높은 쪽을 이어받고, 다음 레벨까지 모은 경험치는 0 에서 시작**한다
- 상위 갈래는 지금 코드(`JXp = 0`)가 이 규칙이다
- **같은 종류 조커 합치기도 같다** (임씨 11/28 추가 확정): 레벨은 높은 쪽, 경험치 0. 예전엔 높은 쪽 경험치를 이었다 (`MergeJokers` 같은 조커 갈래에 `JXp = 0` 추가)

## 이유
임씨: 다른 디펜스 게임들도 합치면 0 으로 시작한다. 그렇게 하자. 같은 종류 합치기도 0 으로.
- QA 39 가 "레벨 6 경험치 69/70 + 레벨 4 → 상위 조커 레벨 6 경험치 0" 을 버그 후보로 올렸지만, 의도한 동작으로 확정한다
- 잃는 양은 한 레벨 안의 진행분뿐이고, 상위 조커는 이미 위력 합 × 1.3 / × 1.5 와 늘 강화를 받는다

## 대안
- 레벨이 가장 높은 재료의 경험치를 잇기 (같은 조커 합치기와 같게, QA 39 안): 고르지 않음
