# D-498. 족보 메뉴판 로고 관 선을 1.5배 → 1배로

- 날짜: 2026-11-28
- 상태: 확정
- 이슈: #53
- 대체: D-495 의 '관 선 1.5배를 인게임에도' (번짐 · 크기 · −8° 기울기는 그대로)

## 결정
- 족보 메뉴판(인게임 왼쪽 위) BAR Alice 로고의 관 선 배율을 1.5 → 1.0 으로 (0.5 줄임). 시작 화면은 1.5 그대로
- `PaintAliceSign` 의 Wall 인자가 시작 화면(1) · 인게임(0)을 가른다: 관 선 배율만 다르고 번짐 폭은 같다

## 이유
사용자: 간판은 0.5배 굵기 줄여 달라. 실제 게임 촬영(`DOC/assets/images/ingame-logo/logo_compare_ingame.png`)에서 폭 100 로고에 1.5배 관을 그리니 BAR 두 겹 테가 꽉 찬 글자처럼 뭉치고 잔 위 반짝이가 덩어리졌다.

## 대안
- 로고를 키우고 '족보 메뉴' 제목을 내리기: 아래 메뉴 줄이 모두 밀린다
