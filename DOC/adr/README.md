# 결정 기록 (ADR)

결정 한 건당 한 장으로 남긴다. 번호는 예전 의사결정 기록의 D-번호를 이어 쓴다.

- **옛 기록**: D-001 ~ D-478 은 [D-001-478-legacy-log.md](D-001-478-legacy-log.md) 한 장에 표로 있다. 더 고치지 않는다 (그 안의 결정을 뒤집을 때도 새 ADR 을 쓴다).
- **새 기록**: `D-<번호>-<짧은-영문-이름>.md`. 새 ADR 을 쓰기 전에 **main 의 최신 번호를 확인**하고 다음 번호를 쓴다.
- **뒤집기**: 옛 결정을 바꾸면 새 기록을 만들고, 옛 기록의 상태를 `폐기 (D-xxx 로 대체)` 로 고친다. 옛 표 안의 결정이면 새 기록에 무엇을 대체하는지 적는다.

## 양식

```markdown
# D-000. 제목

- 날짜: YYYY-MM-DD
- 상태: 확정 | 폐기 (D-xxx 로 대체)
- 대체: (있으면) D-xxx

## 결정
## 이유
## 대안
```
