# D-480. 방울 멈춤을 둔화와 따로 둔다

- 날짜: 2026-11-27
- 상태: 확정
- 이슈: #5

## 결정
- 방울(과 흰 토끼)의 멈춤은 적의 `StopT`(멈춤 남은 시간)로 넣는다. 둔화(`SlowT` · `SlowAmt`)와 따로 줄고, 멈춤 중엔 움직이지 않는다
- 둔화가 끝나면(`SlowT` 0) 둔화 세기 `SlowAmt` 도 0으로 지운다
- 화면의 얼음빛은 둔화 또는 멈춤 중 긴 쪽으로 그린다

## 이유
예전엔 방울이 `SlowAmt = 1`(둔화 100%)로 멈추게 했고, 둔화를 맞을 때 `SlowAmt = max(지금, 새 둔화)` 라 한 번 100%가 되면 다른 둔화를 계속 맞는 동안 100%가 남았다. ♣ 타워 같은 둔화가 이어지면 적이 **영원히 멈춘다**. 길 초입에서 멈춘 적에게 공격이 안 닿으면 웨이브가 끝나지 않는다 (봇 30 모드 씨앗 2, 21웨이브에서 재현, 이슈 #5). 설명대로 "8초마다 1.5초 멈춤" 이 되게 고친다.

## 대안
- `Hit` 에서 둔화 세기를 max 대신 새 값으로 덮기: 센 둔화가 약한 둔화에 지워져 ♣ 강화가 약해진다
- 방울이 멈춤 끝에 `SlowAmt` 를 되돌리기: 멈춤 중 들어온 다른 둔화 값을 잃는다
