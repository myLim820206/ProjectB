# D-496. 족보 메뉴판 줄은 한 줄 크게, 설명은 툴팁으로

- 날짜: 2026-11-28
- 상태: 확정
- 이슈: #58
- 대체: D-263 · D-403 의 '줄 = 이름 ····· ×배수, 아래 작은 설명' 두 단 구성

## 결정
- 족보 메뉴판 줄에는 이름과 배수만 한 줄로 크게 쓴다. 이름 = 밝은 크림 `#ece6d6` 굵게 15px (칸에 안 들어가면 1.5px씩 12px까지 줄인다), 배수 = 금색 `#ffd96a` 굵게 15px. 점선 리더는 이름 색 28%
- 작은 설명 줄(8.5px)은 뺀다. 마우스를 올린 줄 오른쪽(판 위)에 툴팁: 족보 색 굵은 이름 13px + 효과 글 11.5px (`PaintHandMenuTip`, 판 위 UI 위에 그린다)
- 합성 · 먹이 알약은 배수 왼쪽, 줄 가운데. 줄 상자 31 → 33 (줄 사이 6.4 → 4.4)
- 플러시 · 스트레이트의 '(3~5장)' 은 툴팁 이름에만 붙인다
- 시험용 `-pdmenuhover=족보번호`: 그 줄에 마우스를 둔 채 시작 (툴팁 촬영)
- 비교 그림: `DOC/assets/images/hand-menu-text/hand_menu_compare.png` (실제 빌드 1920×1080 촬영)

## 이유
사용자: 족보 글씨가 잘 안 보인다. 설명 줄이 6pt 라 1080p 에서도 읽히지 않았고, 이름도 보통 굵기 회색이라 흐렸다. 지금 판은 합성 배지가 배수 x1.5 를 가리기도 했다. 시안 3개(크게 · 밝게 / 족보 색 이름 / 한 줄 + 툴팁)를 찍어 비교했고 사용자가 한 줄 + 툴팁을 골랐다.

## 대안
- 시안 1 크게 · 밝게 (두 단 유지, 설명 10.5px): 정보는 다 보이지만 줄이 빽빽하다
- 시안 2 이름을 족보 색으로: 판 장판과 색이 이어지지만 플러시 · 스트레이트 보라가 비슷해 보인다
