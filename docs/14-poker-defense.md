# 14. 포커 디펜스 (가칭)

다른 세션에서 넘어온 기획 메모(아이디어 단계)를 정리하고, 첫 프로토타입을 만들었다.
프로토타입: [prototype/poker-defense](../prototype/poker-defense/README.md)

## 1. 한 줄 요약
포커 카드로 타워를 세우는 디펜스 게임. 카드 한 장이 타워 하나이고, 인접한 타워끼리 포커 족보가 맞으면 시너지가 발동한다. 그래픽은 도형만 사용한다.

## 2. 배경 / 목표 (메모의 결정 사항)
- 소규모 유료 게임 (판매가 1~2천원 수준). 가볍게, 빨리 만들어서 내본다
- 도형(원, 삼각형, 사각형 등)만으로 모든 그래픽을 구성
- 이전 시도에서 얻은 교훈
  - 스택 포커(내려오는 카드를 클릭해 족보 만들기): 화면에서 족보를 눈으로 찾는 것이 고민이 아니라 노동에 가까워 보류
  - 테트리스 + 디펜스: 비슷한 게임이 이미 많아 보류
- 디펜스는 웨이브 사이에 숨 돌리는 템포가 있어서, 그때 패를 보고 고민하는 구조가 잘 맞음

## 3. 핵심 루프
1. 웨이브 사이에 카드 몇 장을 뽑는다
2. 카드를 맵에 놓아 타워로 설치하거나, 손에 들고 다음 웨이브까지 아껴 둔다
3. 웨이브를 막는다
4. 반복. 중간중간 규칙을 바꾸는 보상을 고른다 (v1에는 없음)

## 4. 핵심 메커닉 (메모의 제안 방향)
- 카드 = 타워. 무늬 = 속성/공격 타입, 숫자 = 공격력
- 인접 타워의 카드 조합이 족보가 되면 시너지. 족보마다 효과를 다르게 해서 크기만이 아니라 상황에 따라 고르게
  - 예: 원 페어 공격력, 플러시 범위, 스트레이트 연사, 풀하우스 범위+연사, 포카드 강력한 한 방
- 핵심 고민: "하트 7 옆에 하트 9를 둬서 플러시를 노릴까, 스페이드 7을 둬서 페어를 노릴까"
- 고르는 재미 장치: 카드를 쓰면 없어진다, 손패 칸 제한, 족보마다 효과가 다르다

## 5. 미정 사항 → v1 프로토타입에서 고른 기본값
| 미정 사항 | v1 기본값 | 이유 |
|---|---|---|
| 시너지 단위 | 카드 한 장 = 타워 + 인접 시너지 | 메모 추천안 |
| 인접 판정 | 가로·세로 한 줄로 붙은 연속 2~5장. 가로·세로 둘 다 걸리면 효과 둘 다 | 줄이 눈에 보여 족보 읽기가 가장 쉬움. 교차점이 배치 고민거리 |
| 한 줄의 족보 고르기 | 큰 족보부터 겹치지 않게 | 7 7 7이면 페어가 아니라 트리플 |
| 플러시·스트레이트 장수 | 3~5장, 장수가 많을수록 강함 | 5장만 인정하면 초반에 거의 안 나옴 |
| 덱 구조 | 고정 52장 (A~K × 4무늬) | 루프 손맛 확인이 먼저. 덱빌딩은 다음 |
| 맵 | 정해진 길 하나 + 길 아닌 칸 자유 배치, 16 × 10칸 | 디펜스 기본형 |
| 카드 공급 | 처음 5장, 웨이브마다 3장, 손패 최대 7장 | 아껴 두기와 버리기 고민 |
| 교체 | 타워 위에 카드를 놓으면 교체 (원래 카드는 버려짐) | 족보 다시 짜기 |
| 무늬 → 도형 | ♠ 파란 삼각형(저격), ♥ 빨간 원(폭발), ♦ 노란 마름모(연사), ♣ 초록 사각형(둔화) | 메모 예시 그대로 |
| 숫자 표현 | 도형 안에 글자 (2~10, J Q K A) | 점 개수는 10 이상에서 읽기 어려움 |
| 보상 | 없음 | 루프 먼저 |
| 엔진 | 웹 프로토타입 (확정 아님) | |

## 6. v1 시험 결과
| 봇 (6판) | 결과 |
|---|---|
| 족보를 생각하는 봇 | 5판 전부 통과(15웨이브), 1판 15웨이브에서 실패, 남은 목숨 평균 8.7 |
| 족보를 생각 안 하는 봇 | 6판 모두 11웨이브에서 실패 |

적 체력은 웨이브마다 ×1.37. 족보를 쓰지 않으면 후반을 못 버티게 맞췄다.

## 7. 확인할 것 (플레이 테스트)
- 놓기 전 고민이 생기는가 (페어로 바로 쓸까, 플러시를 기다릴까)
- 손패를 아끼는 선택이 실제로 이득이 되는 순간이 있는가 (봇은 안 아끼고도 이김 → 아끼기 보상이 약할 수 있음)
- 무늬별 공격 차이가 체감되는가
- 다음 단계 후보: 웨이브 사이 보상(규칙 카드, docs/11), 덱빌딩, 맵 여러 개

## 8. 범위 가이드 (메모)
1~2천원 규모. 핵심 루프 프로토타입 → 족보 시너지 손맛 확인 → 도형 아트/이펙트 → 볼륨(스테이지, 보상).
