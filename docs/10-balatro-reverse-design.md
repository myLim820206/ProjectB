# 10. 발라트로 역기획

테트리스 포커의 라운드 사이 성장 구조를 설계하기 전에, 참고작인 발라트로(Balatro)를 뜯어본다.
수치는 기본 난이도(화이트 스테이크) 기준이며 기억에 기반한 값이라, 실제로 쓰기 전에 위키나 게임에서 다시 확인한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 개발 | LocalThunk (1인 개발), 퍼블리셔 Playstack |
| 출시 | 2024년 2월, PC → 콘솔·모바일 |
| 엔진 | LÖVE (Lua) |
| 가격 | 약 15달러 |
| 장르 | 포커 족보 기반 덱빌딩 로그라이크 |
| 한 판 길이 | 30분~1시간 (8앤티 클리어 기준) |
| 성과 | 수백만 장 판매, 2024년 주요 게임상 다수 수상 |

한 줄 요약: **누구나 아는 포커 족보로 점수를 내고, 판마다 다르게 모이는 조커로 점수 공식을 부순다.**

## 2. 핵심 루프

```
블라인드 선택 → 손패로 족보 내기(점수 달성) → 보상 받기 → 상점에서 강화 → 다음 블라인드
```

### 2.1 판 구조
- 앤티(Ante) 8개. 앤티마다 블라인드 3개: 스몰(목표 ×1), 빅(×1.5), 보스(×2)
- 앤티별 기본 목표 점수: 300 / 800 / 2,000 / 5,000 / 11,000 / 20,000 / 35,000 / 50,000
  - 1앤티 스몰 300, 빅 450, 보스 600 → 8앤티 보스 100,000
  - 앤티마다 2~2.5배씩 오른다. 플레이어의 점수도 곱셈으로 커져야 따라갈 수 있다
- 스몰·빅 블라인드는 건너뛸 수 있다. 건너뛰면 보상과 상점을 포기하고 태그(다음 상점 무료 조커, 팩 무료 등)를 받는다
- 8앤티를 깨면 승리, 이후 무한 모드로 계속 가능

### 2.2 한 블라인드 안
| 자원 | 기본값 | 역할 |
|---|---|---|
| 손패 | 8장 | 덱(52장)에서 뽑음 |
| 핸드(내기) | 4번 | 최대 5장을 내서 족보로 점수 |
| 버리기 | 3번 | 최대 5장 버리고 새로 뽑음 |

- 핸드를 다 쓰기 전에 목표 점수를 넘기면 통과. 못 넘기면 그 판(런) 끝
- 버리기는 "원하는 족보를 찾는 시간". 핸드는 "점수를 내는 시간". 둘 다 한정이라 매 턴 선택이 생긴다

## 3. 점수 공식

```
점수 = 칩 × 배수
```

### 3.1 계산 순서
1. 족보의 기본 칩과 배수
2. 족보에 쓰인 카드를 왼쪽부터 하나씩: 카드 숫자만큼 칩 추가(2~10은 숫자, J·Q·K 10, A 11), 카드 강화 효과
3. 손에 들고 있는(내지 않은) 카드의 효과 (강철 카드 등)
4. 조커를 왼쪽부터 하나씩 적용
5. 최종 칩 × 최종 배수

- 배수는 **+배수(덧셈)** 와 **×배수(곱셈)** 가 있고, 적용 순서대로 계산한다. 그래서 +배수 조커를 앞에, ×배수 조커를 뒤에 두는 "조커 순서"가 실력 요소가 된다
- 계산 과정을 카드 하나하나 숫자가 튀어 오르며 보여 준다. 숫자가 폭발하는 연출이 이 게임 쾌감의 절반

### 3.2 족보 (기본값)
| 족보 | 칩 × 배수 | 행성 카드 1레벨당 |
|---|---|---|
| 하이 카드 | 5 × 1 | +10 / +1 |
| 원 페어 | 10 × 2 | +15 / +1 |
| 투 페어 | 20 × 2 | +20 / +1 |
| 트리플 | 30 × 3 | +20 / +2 |
| 스트레이트 | 30 × 4 | +30 / +3 |
| 플러시 | 35 × 4 | +15 / +2 |
| 풀하우스 | 40 × 4 | +25 / +2 |
| 포카드 | 60 × 7 | +30 / +3 |
| 스트레이트 플러시 | 100 × 8 | +40 / +4 |
| 파이브 카드 (숨김) | 120 × 12 | +35 / +3 |
| 플러시 하우스 (숨김) | 140 × 14 | +40 / +4 |
| 플러시 파이브 (숨김) | 160 × 16 | +50 / +3 |

- 숨김 족보는 일반 덱으로는 불가능하고, 덱을 조작(카드 복제, 무늬 변경)해야 나온다. "덱을 깎으면 새 족보가 열린다"는 발견의 재미
- 행성 카드로 족보 레벨을 올린다. 하나의 족보에 집중 투자하는 빌드("페어만 계속 레벨업")가 생긴다

## 4. 성장 요소

### 4.1 조커 (핵심)
- 기본 슬롯 5개. 약 150종. 등급: 일반 / 고급 / 희귀 / 전설
- 효과 유형
  | 유형 | 예시(효과 형태) |
  |---|---|
  | 고정 +배수 | 항상 배수 +4 |
  | 조건부 | 특정 무늬로 낼 때마다 +배수, 페어가 포함되면 +칩 |
  | ×배수 | 특정 조건에서 배수 ×2, ×3 |
  | 성장형 | 조건을 만족할 때마다 영구히 수치가 커짐 (버린 카드 수, 낸 카드 수 등) |
  | 경제 | 라운드 끝에 돈, 이자 상한 증가 |
  | 규칙 변경 | 4장으로 스트레이트·플러시 인정, 모든 카드를 얼굴 카드로 취급 |
  | 복사 | 오른쪽 조커의 효과를 복사 |
- 에디션(조커와 카드에 붙는 희귀 속성): 포일 +50칩, 홀로 +10배수, 폴리크롬 ×1.5배수, 네거티브 슬롯 +1
- 조커 판매 가능. 슬롯 제한 때문에 "무엇을 버릴지"가 계속 고민거리

### 4.2 소모품 (기본 2칸)
| 종류 | 수 | 역할 |
|---|---|---|
| 행성 | 12 | 족보 레벨업 |
| 타로 | 22 | 카드 강화, 무늬 변경, 카드 복제·삭제, 돈 |
| 스펙트럴 | 18 | 강력하지만 대가가 있음 (덱 파괴, 조커 삭제 등) |

### 4.3 카드 개조 (덱빌딩)
| 개조 | 효과 |
|---|---|
| 보너스 | +30칩 |
| 배수 | +4배수 |
| 와일드 | 모든 무늬로 취급 |
| 유리 | ×2배수, 1/4 확률로 깨짐 |
| 강철 | 손에 들고 있으면 ×1.5배수 |
| 돌 | +50칩, 숫자·무늬 없음 |
| 황금 | 손에 들고 라운드 끝나면 돈 |
| 행운 | 확률로 +배수 또는 돈 |
| 봉인 (빨강·파랑·금·보라) | 재발동, 행성 생성, 돈, 타로 생성 |

- 카드 삭제로 덱을 줄여 원하는 카드가 자주 나오게 하는 것도 핵심 전략

### 4.4 바우처
- 상점마다 1개. 판 전체에 영구 적용 (상점 슬롯 +1, 핸드 +1, 버리기 +1, 리롤 할인 등)

## 5. 경제

| 항목 | 값 |
|---|---|
| 블라인드 보상 | 스몰 $3, 빅 $4, 보스 $5 |
| 남은 핸드 | 1개당 $1 |
| 이자 | 가진 돈 $5마다 $1, 최대 $5 (기본) |
| 상점 | 조커·카드 2칸, 부스터 팩 2개, 바우처 1개 |
| 리롤 | $5부터 시작, 할 때마다 +$1 |
| 조커 가격 | 대략 $4~$10 |

- 이자 때문에 "지금 쓰기 vs 모아서 이자 받기" 긴장이 생긴다. $25 이상 모으면 매 라운드 $5 이자
- 남은 핸드가 돈이 되니, 적은 핸드로 빨리 깨는 강한 빌드가 더 부자가 된다 (선순환)

## 6. 보스 블라인드

보스마다 규칙 하나를 비튼다. 빌드의 약점을 찌르는 역할.

| 유형 | 예시(효과 형태) |
|---|---|
| 카드 무력화 | 특정 무늬 카드 점수 없음, 얼굴 카드 점수 없음 |
| 자원 제한 | 핸드 1번, 버리기 0번, 손패 -1 |
| 족보 제한 | 같은 족보 두 번 못 냄, 한 종류 족보만 허용, 반드시 5장 |
| 수치 깎기 | 기본 칩·배수 절반, 내는 족보 레벨 -1 |
| 정보 가리기 | 일부 카드가 뒤집혀 나옴 |
| 목표 증가 | 목표 점수 ×4 |
| 최종 보스 (8앤티) | 목표 ×6, 조커 하나 무력화, 조커 무작위 섞기 등 |

- 다음 보스가 무엇인지 앤티 시작 때 미리 보여 준다. 대비할 시간을 주는 공정함

## 7. 반복 플레이 장치

| 장치 | 내용 |
|---|---|
| 덱 15종 | 시작 조건이 다름 (버리기 +1, 돈 +$10, 조커 슬롯 +1 대신 핸드 -1, 무늬 2개만 등) |
| 스테이크 8단계 | 덱마다 난이도 단계를 올림. 단계마다 불리한 규칙이 누적 |
| 해금 | 조커·덱·바우처가 플레이 조건 달성으로 열림. 컬렉션 채우기 |
| 챌린지 | 특수 규칙의 고정 시나리오 |
| 시드 | 같은 시드로 같은 판 재현 |

조합 수 = 덱 15 × 스테이크 8 × (조커 150종 중 5슬롯 조합) → 같은 판이 사실상 없다.

## 8. 왜 재미있나 (분석)

1. **배울 게 거의 없다.** 포커 족보는 이미 다 안다. 처음 30초 만에 무엇을 해야 할지 안다
2. **숫자가 폭발한다.** 칩 × 배수, 그 배수에 ×배수가 또 곱해진다. 후반엔 점수가 수십만~수백만으로 튄다. 숫자 커지는 쾌감이 직관적
3. **빌드가 나만의 것이 된다.** 같은 조커도 다른 조커와 만나면 의미가 달라진다. 판마다 "이번엔 플러시 빌드" 같은 정체성이 생긴다
4. **운을 선택으로 덮는다.** 카드 뽑기는 운이지만 버리기, 상점, 조커 순서, 건너뛰기 등 선택지가 많아 "내가 망쳤다/잘했다"로 느껴진다
5. **정보가 투명하다.** 다음 보스, 점수 계산 과정, 조커 효과가 다 보인다. 계산해서 이길 수 있다
6. **짧은 결정 단위.** 한 핸드 = 한 결정. 멈췄다 생각해도 되는 턴제라 부담 없음
7. **아트가 단순하다.** 카드, 조커 일러스트, CRT 느낌 효과. 1인 개발 규모로 가능한 화면

## 9. 테트리스 포커에 가져올 것

| 발라트로 | 테트리스 포커에 대응 | 메모 |
|---|---|---|
| 칩 × 배수 | 이미 있음 | 유지 |
| 앤티 3블라인드 | 라운드 8개 → 앤티 구조 검토 | 스몰·빅·보스로 쪼개면 상점 방문 횟수가 늘어 빌드가 더 자람 |
| 핸드·버리기 | 블록 40개 + 보관(HOLD) | "버리기"에 해당하는 자원 추가 검토 (블록 버리기, 카드 한 장 지우기) |
| 조커 | **규칙 카드** (가칭) | 낙하 퍼즐에 맞춘 효과: "가로 카드는 배수 +2", "연쇄 2단계부터 ×1.5", "원 페어도 터짐(칩 0)" |
| 행성 (족보 레벨업) | 족보 레벨업 | 그대로 쓰기 쉬움 |
| 타로 (카드 개조) | 덱 카드 개조 | 와일드(모든 숫자로 취급), 유리, 돌 등. 퍼즐에서는 "판 위 카드 한 장 바꾸기"도 가능 |
| 숨김 족보 | 덱 조작으로 열리는 족보 | 같은 무늬만 남긴 덱 → 플러시 연쇄 빌드 |
| 이자 경제 | 돈 = 남은 블록 수 + 이자 | 빨리 깰수록 부자 |
| 보스 규칙 | 이미 3종 있음 | 퍼즐 고유 보스로 확장: 판 좁아짐, 낙하 속도 2배, 가로 카드 금지 |
| 다음 보스 미리 공개 | 추가 | 공정함 |
| 덱 종류·난이도 단계 | 출시 반복성 핵심 | 덱 5종 × 단계 5개 정도로 시작 |

### 우리만의 차별점 (발라트로에 없는 것)
- **배치가 곧 손패.** 발라트로는 손패를 고르지만, 우리는 블록을 어디에 떨어뜨릴지로 족보를 만든다. 판에 남은 카드가 다음 수의 재료라 계획의 깊이가 다르다
- **연쇄.** 한 번의 낙하가 여러 족보를 연달아 터뜨린다. 발라트로의 "한 핸드 = 한 족보"보다 큰 한 방
- **실시간 압박.** 낙하 속도가 있어 생각할 시간이 제한된다 (발라트로는 완전 턴제)

### 주의할 점
- 게임 규칙과 구조(칩 × 배수, 상점, 조커 개념)는 저작권 대상이 아니다. 하지만 조커 이름, 효과 문구, 일러스트, UI 배치, "블라인드·앤티" 같은 고유 용어를 그대로 쓰면 "베꼈다"는 인상과 분쟁 위험이 커진다. 용어와 효과는 우리 식으로 새로 만든다
- 조커 150종은 1인 개발에 과하다. 처음에는 규칙 카드 40~60종이면 충분 (네온 선 아이콘이라 아트 부담은 작음)
- 발라트로가 워낙 유명해서 "테트리스 + 발라트로"로 소개될 것. 장점(이해가 빠름)이자 단점(비교당함). 연쇄와 배치 퍼즐을 앞에 내세운다
