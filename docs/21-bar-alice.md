# 21. 바 앨리스 (게임 이름과 세계관)

최종 수정: 2026-11-16
관련 결정: D-309 (이름 · 세계관). 예전 이름 네온 팔라스(D-246, D-252)를 대신한다.

## 1. 이름

| 항목 | 한국어 | 영어 |
|---|---|---|
| 이름 | **바 앨리스** | **Bar Alice** |
| 부제 | **카드 병정들의 반란** | **Rebellion of the Card Soldiers** |
| 스팀 표기 | 바 앨리스: 카드 병정들의 반란 | Bar Alice: Rebellion of the Card Soldiers |

- 표기는 '앨리스' (외래어 표기법·국내 관용). '엘리스' 아님.
- '네온'은 이름에서 뺀다. 네온은 스크린샷이 보여 주고, 태그·설명문에 넣는다.
- 같은 이름의 게임 없음 (2026-11-16 검색). 같은 장르의 'ACE: Alice Card Episode'(발라트로식 덱빌딩)와 'Alice'가 겹치므로 스토어에서는 부제를 항상 붙인다.
- 원작(루이스 캐럴)은 저작권이 끝났다. 디즈니 앨리스 모습(파란 원피스, 금발 머리띠 등)은 따르지 않는다.

## 2. 세계관 (한 줄)

> 하트 여왕의 폭정에 카드 병정들이 반란을 일으켰다. 거점은 이상한 나라 뒷골목의 네온 바 '앨리스'. 여왕의 군대가 쳐들어오고, 카드 병정과 조커들이 바를 지킨다.

| 게임 속 | 세계관 |
|---|---|
| 카드 타워 | 반란을 일으킨 카드 병정 |
| 족보 · 합성 | 병정들이 대열을 짜고 하나로 뭉침 |
| 조커 · 상위 조커 | 반란군에 가담한 이상한 나라 사람들 |
| 칵테일 | 바에서 내주는 술 ('Drink Me') |
| 적 · 보스 13 | 여왕의 군대 |
| 최종 보스 | 하트 여왕 (나중에, 지금은 그 웨이브 보스 체력 ×3, D-229) |
| 시작 화면 · 메뉴 · 주크박스 · LAST CALL | 바 '앨리스'의 간판과 물건 |

## 4. 정할 것

| # | 질문 | 추천 |
|---|---|---|
| 1 | 상위 조커 '하트 왕 · 하트 잭'은 여왕 편인데 우리 편이어도 되나 | 그대로 둔다. '여왕을 배신하고 반란에 가담'으로 설명. 하트 '여왕'은 상위 조커에 없으므로 최종 보스로 남긴다 |
| 2 | 보스 13종 이름을 여왕 군대로 (방패 거인 → 근위대장 등) | 이름만 바꾼다 (능력·모양 그대로). 일이 작고 세계관이 바로 산다 |
| 3 | 일반 적(Normal·Fast·Tank …) 이름 | 그대로. 화면에 이름이 거의 안 나온다 |
| 4 | 이야기 연출 (오프닝 · 엔딩) | 시작 화면에 한 줄 + 30 모드 클리어 때 짧은 글 한 장. 컷신은 안 만든다 |
| 5 | 앨리스는 화면에 나오나 | 나오지 않는다 (바 이름일 뿐). 캐릭터 그림을 피해서 일이 커지지 않게, 디즈니 모습 위험도 없음 |
