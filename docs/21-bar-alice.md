# 21. 바 앨리스 (게임 이름과 세계관)

최종 수정: 2026-11-16
관련 결정: D-309 (이름), D-310 (컨셉: 이야기 없이 분위기), D-311 (부제). 예전 이름 네온 팔라스(D-246, D-252)를 대신한다.

## 1. 이름

| 항목 | 한국어 | 영어 |
|---|---|---|
| 이름 | **바 앨리스** | **Bar Alice** |
| 부제 | **늦은 밤의 포커** | **Late Night Poker** |
| 스팀 표기 | 바 앨리스: 늦은 밤의 포커 | Bar Alice: Late Night Poker |

- 표기는 '앨리스' (외래어 표기법·국내 관용). '엘리스' 아님.
- '네온'은 이름에서 뺀다. 네온은 스크린샷이 보여 주고, 태그·설명문에 넣는다.
- 같은 이름의 게임 없음 (2026-11-16 검색). 같은 장르의 'ACE: Alice Card Episode'(발라트로식 덱빌딩)와 'Alice'가 겹치므로 스토어에서는 부제를 항상 붙인다.
- 원작(루이스 캐럴)은 저작권이 끝났다. 디즈니 앨리스 모습(파란 원피스, 금발 머리띠 등)은 따르지 않는다.

## 2. 컨셉 (D-310): 이야기 말고 분위기

> 늦은 밤, 바 '앨리스'의 카운터. 칵테일 한 잔을 옆에 두고 포커를 즐기는 남자.

이야기(반란 · 여왕 · 오프닝/엔딩)는 만들지 않는다. 플레이어가 그 남자이고, 게임은 그가 바에서 보내는 한 판이다.

| 게임 속 | 분위기 |
|---|---|
| 판 | 바 테이블 위의 카드 |
| 칵테일 | 한 잔 시켜 마시면 힘이 남 (셰이커 연출 D-306) |
| 시작 화면 · 메뉴 · 주크박스 · LAST CALL | 바의 간판과 물건 |
| 음악 | 늦은 밤 바의 라운지 · 재즈 느낌 (지금 합성음 음악에서 방향 맞추기) |
| 남자 | 얼굴은 그리지 않는다. 보인다면 화면 가장자리의 손 · 잔 · 담배 연기 같은 네온 선 (docs/15 화풍) |

판매 문구 쪽: '편안한 늦은 밤 + 빌드가 터지는 쾌감'. 태그 후보 Relaxing · Roguelike Deckbuilder · Tower Defense · Card Game.
