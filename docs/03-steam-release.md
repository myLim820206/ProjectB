# 03. Steam 출시 계획

최종 수정: 2026-11-05

## 1. 출시 개요

| 항목 | 내용 |
|---|---|
| 플랫폼 | Steam (Windows, macOS) |
| 출시 형태 | 미정 (앞서 해보기 또는 정식 출시) |
| 가격 | 미정 |
| 목표 시기 | 미정 |
| 지역 | 전 세계, 가격은 Steam 권장 지역 가격 참고 |

## 2. Steamworks 준비

1. Steamworks 파트너 계정 등록 (사업자 정보, 세금 정보, 은행 정보 제출)
2. 앱 등록 수수료 납부 후 App ID 발급
3. 개발 팀원에게 Steamworks 권한 부여
4. 개발용 Depot 구성: Windows용과 macOS용 Depot을 분리
5. 테스트용 빌드 브랜치 설정 (기본 `default`, 테스트용 비공개 브랜치)

Steamworks 계정 정보와 키는 저장소에 절대 넣지 않습니다. 비밀 값은 별도 보관소에서 관리합니다.

## 3. 스토어 페이지

| 자료 | 규격 | 상태 |
|---|---|---|
| 캡슐 이미지 (여러 크기) | Steamworks 가이드 규격 | 미착수 |
| 스크린샷 | 최소 5장 | 미착수 |
| 트레일러 | 1편 이상 | 미착수 |
| 설명문 | 짧은 설명, 상세 설명 | 미착수 |
| 시스템 요구 사양 | Windows, macOS 각각 최소와 권장 | 기술 계획 확정 후 |
| 지원 언어 표기 | 인터페이스, 음성, 자막 구분 | 현지화 결정 후 |
| 태그, 장르 | | 콘셉트 확정 후 |

스토어 페이지는 출시 전 Steam 검토를 받아야 하며, 출시일 기준 최소 2주 이상 공개되어 있어야 합니다. 스토어 페이지 공개 시점을 로드맵에 포함합니다.

## 4. 빌드 제출

### 4.1 Windows
- 64비트 패키징 빌드
- Steam DRM 래핑 여부 결정 (선택 사항)
- 설치 스크립트가 필요한 재배포 패키지 (Visual C++ 런타임 등) 등록

### 4.2 macOS
- Apple Silicon 네이티브 포함 (Universal 또는 ARM64 전용은 기술 계획에서 결정)
- 앱 번들 서명과 공증 여부를 출시 전 확인하여 Gatekeeper 경고가 뜨지 않도록 함
- 실행 권한과 번들 구조가 Steam 업로드 후에도 유지되는지 검증

### 4.3 공통
- Steam 오버레이 동작 확인
- Steam 클라이언트 없이 실행 시 Steam 재시작 처리 확인
- 도전과제, 클라우드 세이브 동작 확인
- 오프라인 모드 동작 확인
