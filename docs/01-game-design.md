# 01. 게임 기획서 (Game Design Document)

최종 수정: 2026-11-05
상태: 기획안 2개 비교 중. 하나를 고르면 이 문서에 상세 기획을 합칩니다.

## 1. 확정된 공통 사항

| 항목 | 내용 |
|---|---|
| 장르 | 경영 시뮬레이션 |
| 배경 | 조선 (역사 판타지 허용, 실존 인물과 실제 사건은 직접 다루지 않음) |
| 아트 | 한국형 HD-2D, 쿼터뷰 디오라마, 시간대와 계절 조명 |
| 핵심 시스템 수 | 3개 이내 |
| UI 언어 | 한지, 두루마리, 먹 글씨, 낙관 |
| 조작 | 마우스 중심, 게임패드 지원 |
| 언어 | 한국어 기본, 영어 추가. 처음부터 언리얼 현지화 시스템으로 문자열 관리 |
| 음악 | 국악 악기 기반 검토 (조달 방식 미정) |

## 2. 기획안

| 기획안 | 피치 | 상태 |
|---|---|---|
| [A. 퇴마청](concepts/A-toemacheong.md) | 마물 퇴치 관청의 수령이 되어 퇴마사를 모으고, 사건을 결재해 파견하고, 관아를 키운다 | 보류 (킵) |
| [B. 주막 경영](concepts/B-jumak.md) | 낡은 주막과 빚을 물려받아, 낮에는 길손에게 밤에는 요괴에게 밥과 술을 내며 주막을 키운다 | 구체화 중 (v0.2) |

## 3. 비교

| 기준 | A. 퇴마청 | B. 주막 경영 |
|---|---|---|
| 차별성 | 상. "조선 퇴마 관청"이라는 설정 자체가 훅 | 중. 요리 경영은 흔한 장르. 밤 주막 변형을 넣으면 상 |
| 대중성 | 중. 설정에 끌리는 층이 분명하지만 좁을 수 있음 | 상. 코지 경영은 폭넓게 팔림 |
| 반복성 | 상. 임기 단위로 다시 시작하는 구조가 기본 | 중. 키우면 끝나는 성장형. 지역 시나리오로 보완 |
| 아트 부담 | 중. 퇴마사 동작은 적고 요괴는 정지 스프라이트 | 중상. 손님의 걷기, 앉기, 먹기 동작이 많음 |
| 프로그래밍 부담 | 중. 파견 판정은 계산 위주 | 중상. 손님 동선, 자리 배정, 실시간 영업 처리 |
| 글 작업량 | 많음. 사건 의뢰서 40~60건 | 중간. 손님 대사와 단골 이야기 |
| 홍보 장면 | 요괴 사건 연출, 관아 디오라마 | 북적이는 주막, 초롱 켜진 밤 풍경 |
| 뱀서류와 중복 | 없음 | 없음 |

## 4. 결정에 필요한 질문

1. 넓게 팔리는 편안한 게임(B)과 확실한 훅이 있는 게임(A) 중 무엇을 우선하는가
2. B를 고른다면 밤 주막(요괴 손님) 변형을 넣을 것인가. 넣으면 A의 장점 일부를 흡수한다
3. B를 고른다면 직접 조작형, 운영형, 혼합형 중 어느 방식인가
