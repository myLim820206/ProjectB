# 11. 규칙 카드 기획

테트리스 포커의 라운드 사이 성장 요소. 발라트로의 조커에 해당하지만, **낙하 퍼즐에서만 의미가 있는 조건**(카드 방향, 블록 모양, 연쇄, 낙하, 판 높이)을 중심으로 새로 만든다.
이름 "규칙 카드"는 가칭이다. 아직 프로토타입에는 넣지 않는다.

## 1. 기본 구조

| 항목 | 값 (초안) |
|---|---|
| 슬롯 | 5칸. 바우처로 늘릴 수 있음 |
| 등급 | 일반 / 고급 / 희귀 / 전설 |
| 가격 | 일반 $4~5, 고급 $6~7, 희귀 $8~10, 전설은 상점에 안 나옴(특수 팩에서만) |
| 판매 | 산 가격의 절반 |
| 순서 | 왼쪽부터 적용. 끌어서 순서 바꾸기 가능 |
| 출현 확률 | 일반 70%, 고급 25%, 희귀 5% |

### 1.1 점수 계산 순서 (규칙 카드가 끼어드는 자리)

연쇄 한 단계에서 터진 족보마다:
1. 족보 기본 칩·배수 + 터진 카드 숫자(칩)
2. 플러시면 배수 ×2
3. **규칙 카드를 왼쪽부터** 적용 (+칩, +배수, ×배수, 그 족보에 해당하는 것만)

그 단계의 족보 점수를 모두 더한 뒤:

4. × 연쇄 단계 × 연쇄 스트레이트
5. **연쇄 단계 전체에 거는 규칙 카드** (예: "2연쇄 이상이면 ×1.5")

- 족보 하나에 거는 효과와 연쇄 한 번 전체에 거는 효과를 나눠서, "족보 빌드"와 "연쇄 빌드"가 다르게 느껴지게 한다
- 발동하면 카드가 깜빡이고 숫자가 튀어 오른다 (발라트로식 계산 연출을 짧게, 낙하가 멈추지 않을 만큼)

### 1.2 설계 원칙
1. **판을 보는 눈을 바꿔야 한다.** 산 순간부터 "가로로 눕혀야겠다", "7을 모아야겠다"처럼 배치가 달라져야 좋은 카드
2. **조건은 판 위에서 보이는 것만.** 숫자, 무늬, 카드 방향, 블록 모양, 연쇄 단계, 높이. 숨은 확률은 최소
3. **한 줄로 설명된다.** 효과 문구 한 줄, 숫자 하나
4. **위험과 보상.** 판 높이, 보관 금지처럼 플레이를 불편하게 하는 대신 큰 배수
5. 이미 있는 규칙(원 페어 안 터짐, T 블록 없음)을 깨는 카드는 희귀 이상

## 2. 카드 목록 (초안 54종)

표기: 칩 = +칩, 배수 = +배수, ×배수 = 곱하기.

### 2.1 숫자·무늬 (12)
| 이름 (가칭) | 등급 | 효과 |
|---|---|---|
| 하트 수집가 | 일반 | ♥ 카드가 터질 때마다 배수 +2 (♠♦♣ 판본 각각 있음, 4종) |
| 작은 수 | 일반 | A~3이 터질 때마다 칩 +15 |
| 큰 수 | 일반 | 6~7이 터질 때마다 배수 +2 |
| 홀수 | 일반 | 터진 족보의 숫자가 홀수면 배수 +4 |
| 짝수 | 일반 | 터진 족보의 숫자가 짝수면 칩 +40 |
| 행운의 7 | 고급 | 7로 만든 족보는 ×배수 2 |
| 에이스 하이 | 고급 | A가 들어간 족보는 칩 +50 |
| 두 색 | 고급 | 족보가 빨강(♥♦)만 또는 검정(♠♣)만이면 플러시로 친다 (×2) |
| 무지개 | 희귀 | 족보에 무늬 4종이 모두 있으면 ×배수 3 |

| 이름 | 등급 | 효과 |
|---|---|---|
| 누운 카드 | 일반 | 가로 카드가 터질 때마다 배수 +2 |
| 선 카드 | 일반 | 세로 카드가 터질 때마다 칩 +20 |
| 한 방향 | 고급 | 족보가 모두 같은 방향 카드면 ×배수 2 |
| 엇갈림 | 고급 | 족보에 가로·세로 카드가 반씩 섞여 있으면 배수 +8 |
| 긴 막대 | 일반 | I 블록으로 족보를 터뜨리면 칩 +60 |

### 2.3 연쇄 (8)
| 이름 | 등급 | 효과 |
|---|---|---|
| 도미노 | 일반 | 2연쇄 이상이면 그 연쇄 전체 칩 +50 |
| 눈사태 | 고급 | 연쇄 단계마다 배수 +3씩 추가 (1단계 +3, 2단계 +6, ...) |
| 연쇄 반응 | 고급 | 연쇄 배수가 ×n 대신 ×(n+1) |
| 계단 | 고급 | 연쇄 스트레이트가 2단계부터 인정 |
| 여운 | 희귀 | 연쇄가 끝난 뒤, 원 페어가 하나라도 남아 있으면 그중 하나가 터진다 (칩 0, 연쇄 +1) |
| 첫 방 | 일반 | 1단계에서 끝난 연쇄는 배수 +5 (연쇄 못 하는 사람용) |
| 마지막 한 방 | 희귀 | 라운드의 마지막 블록으로 터진 연쇄는 ×배수 3 |

## 3. 빌드 예시

| 빌드 | 핵심 카드 | 플레이가 이렇게 바뀜 |
|---|---|---|
| 연쇄 | 눈사태, 연쇄 반응, 폭포, 계단 | 위에 카드를 쌓아 두고 아래를 터뜨리는 설계형 플레이 |
| 플러시 | 두 색, 플러시 왕, 하트 수집가, 덱 정리 | 덱을 한두 무늬로 깎고 같은 무늬끼리 붙이기 |
| 가로 | 누운 카드, 한 방향, 네모 상자 | 블록을 눕혀서 쌓는 습관, I·O 블록 선호 |
| 숫자 집중 | 행운의 7, 단골 숫자, 복제 | 덱에 7을 늘려 포카드·파이브 카드 노리기 |
| 위험 | 아슬아슬, 무보관, 빠른 손 | 판을 높게 유지하며 큰 배수, 한 번 실수하면 끝 |
| 판 비우기 | 원 페어 해금, 깨끗한 판, 정리벽 | 자주 터뜨려 판을 비우는 안정형. 점수는 작지만 오래 버팀 |

좋은 카드 조합의 기준: **카드 두 장이 서로 다른 축(숫자 + 연쇄, 방향 + 플러시)을 곱하면** 강해진다. 같은 축끼리 겹치면 덧셈에 그친다.

## 4. 균형 목표 (초안)

| 항목 | 목표 |
|---|---|
| 규칙 카드 없이 | 3~4라운드에서 막힘 |
| 일반 카드만 아무거나 5장 | 6라운드 근처 |
| 시너지 맞춘 빌드 | 8라운드 통과, 후반에 한 방 1만~10만 점 |
| 라운드 목표 | 지금(400 → 3,200)보다 가파르게. 라운드마다 약 1.8~2배 |
| 상점에서 사는 수 | 라운드당 1~2장. 8라운드까지 10장 안팎을 거쳐 5장 남김 |

- 처음엔 봇 시험으로 카드별 점수 기여도를 측정하고, 너무 센 카드(혼자서 2배 이상 올리는 것)를 조정한다
- "티 블록", "원 페어 해금"처럼 규칙을 바꾸는 카드는 재미 확인이 먼저. 숫자는 그다음

## 5. 프로토타입에 처음 넣을 12장

빌드 3개(연쇄, 플러시, 가로)가 각각 성립하는지 보는 최소 세트.

| 축 | 카드 |
|---|---|
| 연쇄 | 도미노, 눈사태, 연쇄 반응, 폭포 |
| 플러시 | 하트 수집가(♥), 두 색, 플러시 왕 |
| 가로·모양 | 누운 카드, 한 방향, 네모 상자 |
| 기타 | 행운의 7, 저금통 |

함께 필요한 것:
- 라운드 끝 보상(돈)과 상점 화면 (카드 3장 중 구매, 리롤)
- 슬롯 5칸 표시와 발동 연출
- 데이터 형식: 카드마다 `{ id, name, rarity, price, text, hook, apply }`. `hook`은 `hand`(족보마다), `chain`(연쇄 단계마다), `roundEnd`, `spawn`, `rule` 중 하나

## 6. 남은 질문
- 이름: "규칙 카드"보다 짧고 우리 색이 있는 이름 (예: 네온 → "회로", "칩", "부적")
- 카드 개조(와일드, 유리 등)와 족보 레벨업을 같은 상점에서 팔지, 팩으로 따로 팔지
- 라운드 구조를 발라트로처럼 3단계(작은·큰·보스)로 쪼갤지, 지금처럼 8라운드 한 줄로 갈지
