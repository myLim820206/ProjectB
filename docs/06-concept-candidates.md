# 06. 콘셉트 후보 검토

최종 수정: 2026-11-05
상태: 장르 결정됨 (경영 시뮬레이션). 이 문서는 검토 과정 기록입니다.

## 0. 결과

검토 후보 밖에서 나온 경영 시뮬레이션 안 2개가 최종 후보가 되었고, **주막 경영**으로 확정했다 (D-018).

- A. 퇴마청: 조선 마물 퇴치 관청 경영. 시뮬레이션과 맞지 않아 제외, [기록 보관](concepts/A-toemacheong.md)
- B. 주막 경영: 채택. [01 게임 기획서](01-game-design.md)

아래는 A안 기준으로 정리한 조건 충족 표다. B안도 반복성을 제외하면 같은 조건을 만족한다.

| 조건 | 충족 여부 |
|---|---|
| 반복성 | 임기 단위 반복, 무작위 사건과 인재, 임지 변화 |
| 뱀서류와 중복 회피 | 실시간 액션도, 무작위 빌드 드래프트도 없음. 기획 작업이 거의 겹치지 않음 |
| Claude 아트 적합 | 관아 건물과 소품이 콘텐츠의 중심. 요괴는 정지 스프라이트 |
| HD-2D 궁합 | 같은 공간을 오래 보는 디오라마 경영. 시간대와 계절 조명 활용 |
| 한국형 테마 | 조선 관아, 한복, 설화 요괴 |



## 1. 평가 기준

| 기준 | 설명 |
|---|---|
| 반복성 | 클리어 후에도 다시 할 이유가 구조적으로 있는가. 필수 조건 |
| 1인 완성 가능성 | 시스템 수가 적고 콘텐츠를 반복 제작으로 늘릴 수 있는가 |
| 아트 부담 | 직접 제작하거나 무료/저가 에셋(Fab, Quixel Megascans 등)으로 해결 가능한가 |
| 언리얼 적합도 | 언리얼의 강점(조명, 물리, 3D, Niagara 이펙트)을 살리는가 |
| 가격 적합도 | 2,000원 ~ 5,000원에 구매자가 납득할 분량과 구조인가 |
| 시장성 | 이 가격대 Steam에서 팔린 선례가 있고, 입소문으로 퍼질 여지가 있는가 |

반복성을 만드는 장치는 크게 네 가지입니다. 좋은 후보는 이 중 두 개 이상을 갖습니다.

| 장치 | 설명 |
|---|---|
| 무작위성 | 매 판 다른 맵, 적 배치, 보상 선택지 |
| 메타 성장 | 판이 끝나도 남는 해금과 영구 강화 |
| 숙련과 기록 | 점수, 타임, 리더보드로 실력 향상 자체가 목표 |
| 일일 도전 | 같은 시드로 모두가 경쟁하는 매일 바뀌는 판 |

## 3. 후보

R1과 R5는 제외되었고 R6, R7, R8을 추가했습니다.

### 3.0 2D, HD-2D, Claude 아트 조건의 영향

아트를 Claude가 코드로 만들기 때문에 평가가 바뀝니다.

- 유리: 타일, 블록, 소품, 팔레트 변형으로 늘리는 수집 대상, 정지 스프라이트 몬스터
- 불리: 캐릭터 수가 많거나 동작이 많은 애니메이션
- R3 무브먼트 타임 어택은 조작감의 핵심이 캐릭터 애니메이션이라 최하위로 내린다.

### 3.1 한국형 아트 방향의 영향

한국형 테마를 입히면 각 후보는 이렇게 바뀐다.

| 후보 | 한국형 적용 | 테마 궁합 |
|---|---|---|
| R8. 로그라이트 던전 RPG | 도깨비, 구미호, 귀신 같은 설화 요괴가 나오는 던전. 마을은 한옥 거점, 던전은 고분, 폐광, 산성 | 최상. 설화 요괴가 몬스터 목록을 그대로 채운다 |
| R6. 탐사 회수 로그라이트 | 고분이나 폐광을 파고들어 유물과 광석을 회수 | 상 |
| R7. 낚시 수집 | 한국 강, 계곡, 바다의 물고기 도감. 정자와 나룻배 | 중상 |
| R2. 물리 파괴 점수 | 테마 연결이 약함 | 하 |

### R8. HD-2D 로그라이트 던전 RPG
- 피치: 거점 마을에서 준비하고, 매번 구조가 바뀌는 던전을 내려가며 턴제 전투로 몬스터를 물리친다. 쓰러지면 마을로 돌아와 영구 성장 후 다시 도전한다.
- 레퍼런스: 화면 연출은 Octopath Traveler, 전투 시점은 드래곤 퀘스트(1인칭 정면 전투), 구조는 Darkest Dungeon과 Slay the Spire의 런 방식
- 핵심 루프: 마을 준비 → 던전 진입 → 탐험과 조우 → 턴제 전투 → 보상 선택 → 층 이동과 보스 → 사망 또는 귀환 → 영구 성장 → 재도전
- 반복 장치: 무작위성 (던전 구조, 조우, 보상), 메타 성장
- 핵심 시스템 3개로 제한: 턴제 전투(스킬 포함), 던전 탐험(절차 생성), 성장(장비와 해금)

왜 가능한가:
- HD-2D는 RPG를 위해 만들어진 스타일이고, 미리보기 장면이 이미 RPG 필드 화면이다.
- 정면 시점 전투를 쓰면 전투에 아군 캐릭터 애니메이션이 필요 없다. 몬스터는 정지 스프라이트에 흔들림, 번쩍임, 파티클 효과로 처리한다 (Octopath의 적도 정지 이미지).
- 던전 층은 타일과 블록 조립이라 Claude 아트의 가장 강한 영역이다.
- 몬스터 종류는 형태 몇 개에 팔레트와 부위 변형을 조합해 늘린다.
- 필드에서 걷는 캐릭터는 주인공 1명, 4방향 걷기 3프레임이면 충분하다.

위험:
- 시스템 3개 각각이 다른 후보보다 무겁다. 개발 기간이 가장 길다.
- 전투 밸런스와 스킬 설계에 시간이 많이 든다.
- 이야기 중심 RPG로 범위가 번지기 쉽다. 대사와 퀘스트는 최소화하고 런 구조를 지킨다.
- 가격은 상한(5,000원)에 가깝게 잡아야 분량과 맞는다.

하지 않는 것:
- 이야기 중심의 일회성 RPG. 단판성이고 대사, 맵, 이벤트 분량이 1인 개발 범위를 넘는다.
- 파티 캐릭터 여러 명의 전투 애니메이션.
- 넓은 오픈 필드.

콘텐츠 규모(출시 기준): 던전 테마 3~4, 층당 방 구성 절차 생성, 몬스터 기본 형태 10~12 × 변형 3 = 30~36종, 보스 4, 스킬 30~40, 장비 40~60
판 길이: 런당 20~40분

### R2. 물리 파괴 점수 경쟁
- 피치: 제한 시간과 제한된 도구로 건물이나 구조물을 최대한 무너뜨려 점수를 겨룬다.
- 레퍼런스: Angry Birds 계열 파괴 퍼즐, Teardown의 파괴 쾌감을 짧은 아케이드로 압축
- 핵심 루프: 구조물 관찰 → 도구 선택과 배치 → 연쇄 붕괴 → 점수 → 도구 해금 → 재도전
- 반복 장치: 숙련과 기록, 일일 도전, 메타 성장
- 장점: 언리얼 Chaos 파괴 물리를 가장 직접적으로 살린다. 영상 한 장면으로 재미가 전달되어 홍보에 유리하다. 경쟁작이 적다.
- 단점: 파괴 물리의 성능과 안정성 확보가 기술 위험이다. 장기 반복 재미가 검증되지 않은 형태라 프로토타입 검증이 필수.
- 콘텐츠 규모: 구조물 30~50 (일부 절차 생성), 도구 8~12
- 판 길이: 1~3분

### R3. 무브먼트 타임 어택
- 피치: 달리기, 점프, 대시를 이어 짧은 코스를 최대한 빨리 통과한다.
- 레퍼런스: Neon White, Clustertruck, Ghostrunner의 이동 파트
- 핵심 루프: 코스 도전 → 기록 → 지름길 발견 → 기록 단축 → 다음 코스 해금
- 반복 장치: 숙련과 기록, 일일 도전 (고스트 리플레이와 리더보드)
- 장점: 시스템은 이동 하나. 코스가 짧아서 하나씩 만들며 분량을 늘릴 수 있다. 스피드런 커뮤니티와 잘 맞는다.
- 단점: 조작감 튜닝에 시간이 많이 든다. 코스 디자인 역량이 성패를 좌우한다. 대중성은 R1보다 낮다.
- 콘텐츠 규모: 코스 30~40
- 판 길이: 30초~2분

### R4. 로그라이트 디펜스
- 피치: 거점 하나를 지키며 매 웨이브 사이에 무작위로 제시되는 포탑과 강화를 골라 조합한다.
- 레퍼런스: Rogue Tower, Thronefall
- 핵심 루프: 웨이브 방어 → 보상 3택 1 → 배치와 강화 → 다음 웨이브 → 패배 시 영구 해금
- 반복 장치: 무작위성, 메타 성장
- 장점: 캐릭터 조작이 없어 애니메이션 부담이 적다. 탑다운 시점이라 아트를 단순화하기 쉽다.
- 단점: 밸런스 설계가 복잡하다. 장르 특성상 UI 작업량이 많다. 무작위 3택 1 강화 구조가 개발 중인 뱀서류 프로젝트와 겹친다.
- 콘텐츠 규모: 포탑 12~16, 적 10~12, 맵 3~5
- 판 길이: 15~30분

### R6. 탐사 회수 로그라이트 (다이브 앤 리턴)
- 피치: 산소나 시간이 제한된 상태로 매번 구조가 바뀌는 구역에 들어가 자원을 모으고, 제때 돌아와 장비를 강화해 더 깊이 내려간다.
- 레퍼런스: Dave the Diver의 잠수 파트, Dome Keeper, A Game About Digging A Hole, 익스트랙션 장르의 싱글 축소판
- 핵심 루프: 장비 점검 → 진입 → 탐색과 채집 → 위험과 욕심 사이에서 귀환 판단 → 판매와 강화 → 더 깊이 재진입
- 반복 장치: 무작위성, 메타 성장
- 장점: "조금만 더" 하는 욕심과 귀환 판단이 긴장감을 만들어 짧은 판이 계속 이어진다. 전투가 없거나 가벼워도 성립해서 적 AI와 애니메이션 부담이 적다. 저가 흥행 선례가 많다.
- 단점: 구역 무작위 생성이 필요하다. 상점, 강화, 인벤토리 UI 작업량이 있다.
- 콘텐츠 규모: 구역 테마 4~5, 자원 20~30, 장비 강화 30~40단계
- 판 길이: 3~8분

### R7. 낚시 수집
- 피치: 여러 물가를 돌며 물고기를 낚아 도감을 채우고, 번 돈으로 낚싯대와 미끼를 바꿔 희귀종에 도전한다.
- 레퍼런스: Webfishing, Dredge의 낚시 파트, Cast n Chill
- 핵심 루프: 장소와 미끼 선택 → 캐스팅 → 입질과 손맛 미니게임 → 판매 또는 도감 등록 → 장비 강화 → 새 장소 해금
- 반복 장치: 무작위성 (출현 확률), 메타 성장, 수집
- 장점: 시스템이 단순하고 조작 부담이 낮아 대중성이 넓다. 언리얼의 물과 조명 표현이 강점으로 직결된다. 편안한 분위기라 오래 켜두는 플레이가 가능하다.
- 단점: 도감을 다 채우면 동기가 줄어든다. 손맛 미니게임의 완성도가 전부라 튜닝이 중요하다.
- 콘텐츠 규모: 장소 5~6, 물고기 60~80종, 장비 15~20
- 판 길이: 자유 (한 번 낚기 30초~2분)

## 5. 추천

1순위는 R8, HD-2D 로그라이트 던전 RPG입니다. 단 범위 통제가 조건입니다.

- HD-2D 스타일을 고른 이상 가장 잘 어울리는 장르이고, 화면만으로 무슨 게임인지 전달된다.
- 정면 전투, 정지 몬스터, 블록 던전 구성으로 Claude 아트의 약점(애니메이션)을 피하고 강점(타일, 변형)을 쓴다.
- 런 구조라 반복성 조건을 만족한다.

범위가 커지면 1인 개발로 끝내지 못한다. 그래서 프로토타입 단계에서 아래를 먼저 증명한다.

1. 전투 1회가 2~3분 안에 끝나면서도 선택이 재미있는가
2. 절차 생성 던전 한 층이 반복해도 지루하지 않은가
3. 한 판을 마치고 영구 성장 후 다시 들어가고 싶은가

부담이 너무 크다고 판단되면 R6 탐사 회수 로그라이트가 대안입니다. 시스템이 더 가볍고, 같은 블록 던전 에셋을 재활용할 수 있습니다.
