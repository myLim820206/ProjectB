# 06. 콘셉트 후보 검토

최종 수정: 2026-11-05
상태: 검토 중. 하나를 고르면 01 게임 기획서로 옮기고 이 문서는 기록으로 남깁니다.

## 1. 평가 기준

| 기준 | 설명 |
|---|---|
| 1인 완성 가능성 | 시스템 수가 적고 콘텐츠를 반복 제작으로 늘릴 수 있는가 |
| 아트 부담 | 직접 제작하거나 무료/저가 에셋(Fab, Quixel Megascans 등)으로 해결 가능한가 |
| 언리얼 적합도 | 언리얼의 강점(사실적 조명, 물리, 3D)을 살리는가. 2D 위주라면 언리얼을 쓸 이유가 약하다 |
| 가격 적합도 | 2,000원 ~ 5,000원에 구매자가 납득할 분량과 구조인가 |
| 시장성 | 이 가격대 Steam에서 팔린 선례가 있고, 스트리머나 입소문으로 퍼질 여지가 있는가 |

## 2. 후보

### A. 이상현상 찾기 (Anomaly Spotting)
- 피치: 반복되는 하나의 공간을 지나가며 평소와 다른 점을 찾아 맞히면 전진, 틀리면 처음으로.
- 레퍼런스: 8번 출구, 그 외 다수의 "이상현상" 계열 인디 게임
- 핵심 루프: 공간 관찰 → 이상 여부 판단 → 전진 또는 후퇴 → 반복
- 장점: 공간 하나에 이상현상 변형만 추가하면 되므로 1인 제작에 최적. 언리얼의 사실적 조명과 Megascans로 적은 노력에 높은 시각 품질. 실제 저가 흥행 선례가 많다.
- 단점: 장르가 이미 포화. 공간 테마와 독자적 규칙 하나가 반드시 필요하다.
- 분량: 1~2시간, 이상현상 30~50개

### B. 짧은 1인칭 호러 / 탐험
- 피치: 한 장소에서 벌어지는 30분~1시간짜리 공포 체험.
- 레퍼런스: 저가 단편 호러 인디 게임들
- 핵심 루프: 탐색 → 단서 획득 → 위협 회피 → 다음 구역
- 장점: 언리얼 적합도 최고. 스트리머 반응이 좋고 이 가격대의 대표 장르.
- 단점: 연출, 사운드, 레벨 디자인 부담이 크다. 1회성이라 리뷰가 분량에 민감하다.
- 분량: 30분~1시간 (선형)

### C. 물리 기반 등반 / 챌린지
- 피치: 조작이 어려운 물리 캐릭터로 높은 곳까지 올라가는 고난도 게임.
- 레퍼런스: Getting Over It, Only Up!
- 핵심 루프: 시도 → 실패와 추락 → 재도전
- 장점: 시스템은 조작 하나뿐. 스트리머 친화적이고 화제성이 크다. 언리얼 Chaos 물리 활용.
- 단점: 조작감 튜닝이 성패를 좌우하고 시간이 많이 든다. 레벨 하나가 길고 정교해야 한다.
- 분량: 클리어 1~5시간 (실력에 따라)

### D. 한 화면 물리 퍼즐
- 피치: 작은 방이나 디오라마 안에서 물체를 옮기고 쌓아 목표를 달성하는 퍼즐 스테이지 묶음.
- 레퍼런스: 물리 퍼즐, 디오라마 퍼즐 계열 인디 게임
- 핵심 루프: 상황 관찰 → 배치와 시도 → 해결 → 다음 스테이지
- 장점: 스테이지 단위 제작이라 일정 조절이 쉽다. 아트는 단순 스타일로 충분.
- 단점: 퍼즐 디자인 역량이 필요하고, 눈에 띄는 훅이 없으면 묻히기 쉽다.
- 분량: 30~50 스테이지, 2~3시간

### E. 아레나 점수 경쟁 (Score Attack)
- 피치: 짧은 판을 반복하며 최고 점수를 노리는 3D 아케이드 게임.
- 레퍼런스: 뱀파이어 서바이버류, 아케이드 서바이벌
- 핵심 루프: 판 시작 → 성장 선택 → 생존 → 사망 → 영구 해금 → 재시작
- 장점: 반복 플레이 가치가 높아 저가 대비 만족도가 좋다. Steam 리더보드와 잘 맞는다.
- 단점: 밸런스와 업그레이드 콘텐츠량이 많이 필요하다. 장르 경쟁이 매우 치열하다.
- 분량: 판당 10~20분, 총 5시간 이상 반복

## 4. 추천

1순위는 A, 이상현상 찾기입니다.

- 공간 하나와 이상현상 목록만으로 게임이 성립해서 1인 개발 일정 통제가 가장 쉽다.
- 언리얼의 조명과 무료 사실적 에셋으로 아트 부담 대비 결과물 품질이 높다.
- 2,000원 ~ 5,000원 가격대에서 실제로 성공한 선례가 가장 뚜렷하다.

포화된 장르라는 약점은 아래 두 가지로 차별화해야 합니다.

1. 익숙하지만 아직 덜 쓰인 공간 테마 (예: 한국적인 장소)
2. 기본 규칙에 더하는 고유 규칙 하나 (예: 이상현상을 촬영해서 증명, 시간 제한, 소리로만 판단하는 구간)

B, 단편 호러는 A와 섞을 수 있습니다. 이상현상 찾기에 공포 연출을 얹는 방향이 이 장르의 일반적인 형태입니다.
