# 06. 콘셉트 후보 검토

최종 수정: 2026-11-05
상태: 2차 검토 중. 하나를 고르면 01 게임 기획서로 옮기고 이 문서는 기록으로 남깁니다.

## 1. 평가 기준

| 기준 | 설명 |
|---|---|
| 반복성 | 클리어 후에도 다시 할 이유가 구조적으로 있는가. 필수 조건 |
| 1인 완성 가능성 | 시스템 수가 적고 콘텐츠를 반복 제작으로 늘릴 수 있는가 |
| 아트 부담 | 직접 제작하거나 무료/저가 에셋(Fab, Quixel Megascans 등)으로 해결 가능한가 |
| 언리얼 적합도 | 언리얼의 강점(조명, 물리, 3D, Niagara 이펙트)을 살리는가 |
| 가격 적합도 | 2,000원 ~ 5,000원에 구매자가 납득할 분량과 구조인가 |
| 시장성 | 이 가격대 Steam에서 팔린 선례가 있고, 입소문으로 퍼질 여지가 있는가 |

반복성을 만드는 장치는 크게 네 가지입니다. 좋은 후보는 이 중 두 개 이상을 갖습니다.

| 장치 | 설명 |
|---|---|
| 무작위성 | 매 판 다른 맵, 적 배치, 보상 선택지 |
| 메타 성장 | 판이 끝나도 남는 해금과 영구 강화 |
| 숙련과 기록 | 점수, 타임, 리더보드로 실력 향상 자체가 목표 |
| 일일 도전 | 같은 시드로 모두가 경쟁하는 매일 바뀌는 판 |

## 2. 1차 검토 결과 (기록)

| 후보 | 결과 | 이유 |
|---|---|---|
| 이상현상 찾기 | 제외 | 단판성. 클리어 후 다시 할 이유가 약함 |
| 단편 호러 | 제외 | 단판성. 선형 1회 체험 |
| 물리 등반 | 제외 | 클리어 후 반복 동기가 스피드런 일부에 한정 |
| 물리 퍼즐 | 제외 | 정답을 알면 끝나는 구조 |
| 점수 경쟁 | 2차 후보로 이동 | 반복성 충족 |

## 3. 2차 후보

### R1. 3D 아레나 서바이벌 (서바이버류)
- 피치: 몰려오는 적 무리 속에서 자동 공격 무기를 모으고 조합하며 정해진 시간까지 버틴다.
- 레퍼런스: Vampire Survivors, Brotato, 20 Minutes Till Dawn
- 핵심 루프: 판 시작 → 처치와 경험치 → 레벨업 시 업그레이드 3택 1 → 생존 또는 사망 → 영구 해금 → 재시작
- 반복 장치: 무작위성, 메타 성장, 숙련과 기록
- 장점: 조작이 이동 하나라 구현이 단순하다. 재미 공식이 검증되어 기획 실패 위험이 낮다. 저가 출시로 크게 성공한 선례가 가장 많은 장르.
- 단점: 경쟁작이 매우 많아 테마나 고유 규칙이 필요하다. 무기, 적, 업그레이드 콘텐츠를 꾸준히 채워야 한다. 적 수백 마리의 성능 최적화가 필요하다.
- 콘텐츠 규모(출시 기준): 캐릭터 4~6, 무기 15~20, 적 10~15, 맵 2~3
- 판 길이: 10~20분

### R2. 물리 파괴 점수 경쟁
- 피치: 제한 시간과 제한된 도구로 건물이나 구조물을 최대한 무너뜨려 점수를 겨룬다.
- 레퍼런스: Angry Birds 계열 파괴 퍼즐, Teardown의 파괴 쾌감을 짧은 아케이드로 압축
- 핵심 루프: 구조물 관찰 → 도구 선택과 배치 → 연쇄 붕괴 → 점수 → 도구 해금 → 재도전
- 반복 장치: 숙련과 기록, 일일 도전, 메타 성장
- 장점: 언리얼 Chaos 파괴 물리를 가장 직접적으로 살린다. 영상 한 장면으로 재미가 전달되어 홍보에 유리하다. 경쟁작이 적다.
- 단점: 파괴 물리의 성능과 안정성 확보가 기술 위험이다. 장기 반복 재미가 검증되지 않은 형태라 프로토타입 검증이 필수.
- 콘텐츠 규모: 구조물 30~50 (일부 절차 생성), 도구 8~12
- 판 길이: 1~3분

### R3. 무브먼트 타임 어택
- 피치: 달리기, 점프, 대시를 이어 짧은 코스를 최대한 빨리 통과한다.
- 레퍼런스: Neon White, Clustertruck, Ghostrunner의 이동 파트
- 핵심 루프: 코스 도전 → 기록 → 지름길 발견 → 기록 단축 → 다음 코스 해금
- 반복 장치: 숙련과 기록, 일일 도전 (고스트 리플레이와 리더보드)
- 장점: 시스템은 이동 하나. 코스가 짧아서 하나씩 만들며 분량을 늘릴 수 있다. 스피드런 커뮤니티와 잘 맞는다.
- 단점: 조작감 튜닝에 시간이 많이 든다. 코스 디자인 역량이 성패를 좌우한다. 대중성은 R1보다 낮다.
- 콘텐츠 규모: 코스 30~40
- 판 길이: 30초~2분

### R4. 로그라이트 디펜스
- 피치: 거점 하나를 지키며 매 웨이브 사이에 무작위로 제시되는 포탑과 강화를 골라 조합한다.
- 레퍼런스: Rogue Tower, Thronefall
- 핵심 루프: 웨이브 방어 → 보상 3택 1 → 배치와 강화 → 다음 웨이브 → 패배 시 영구 해금
- 반복 장치: 무작위성, 메타 성장
- 장점: 캐릭터 조작이 없어 애니메이션 부담이 적다. 탑다운 시점이라 아트를 단순화하기 쉽다.
- 단점: 밸런스 설계가 복잡하다. 장르 특성상 UI 작업량이 많다.
- 콘텐츠 규모: 포탑 12~16, 적 10~12, 맵 3~5
- 판 길이: 15~30분

### R5. 짧은 액션 던전 로그라이트
- 피치: 절차 생성되는 방을 내려가며 전투하고 보상을 골라 보스를 잡는다.
- 레퍼런스: Hades, Enter the Gungeon의 축소판
- 반복 장치: 무작위성, 메타 성장
- 장점: 반복성과 대중성 모두 높다.
- 단점: 전투, 적 AI, 절차 생성, 애니메이션이 모두 필요해 1인 저가 게임으로는 범위가 크다.
- 판단: 이번 프로젝트에는 과하다. 기록용으로만 남긴다.

## 5. 추천

1순위는 R1, 3D 아레나 서바이벌입니다.

- 이동 조작 하나와 자동 공격만으로 게임이 성립해서 1인 개발로 완성하기 쉽다.
- 무작위 업그레이드와 영구 해금이 반복 플레이를 구조적으로 보장한다.
- 이 가격대에서 가장 검증된 장르라 기획 실패 위험이 낮다.

포화된 장르라는 약점은 고유 규칙 하나로 차별화합니다. 예시는 다음과 같습니다.

1. 지형 파괴: 무기가 맵의 벽과 구조물을 부수고, 무너진 잔해가 적을 막거나 깔아뭉갠다. R2의 장점을 흡수하는 방향.
2. 공간 제약: 맵이 점점 좁아지거나 바닥이 무너져 위치 선정이 중요해진다.
3. 테마: 한국적인 공간이나 일상 공간 등 아직 덜 쓰인 배경.

R2는 독창성이 가장 높지만 재미가 검증되지 않았습니다. 고른다면 1~2주짜리 프로토타입으로 반복 재미부터 확인해야 합니다.
