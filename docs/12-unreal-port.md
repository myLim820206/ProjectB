# 12. 언리얼 이식

웹 프로토타입(prototype/tetris-poker, v5)을 언리얼 엔진 5 C++ 프로젝트로 옮겼다.
맵, 블루프린트, 에셋 없이 **C++ 코드만으로** 실행된다. 화면은 Slate로 직접 그린다.

## 1. 열어 보기

### Windows
1. Visual Studio 2022에 "C++를 사용한 게임 개발" 워크로드 설치
2. `ProjectB.uproject`를 더블클릭 → "모듈을 다시 빌드할까요?"에서 **예**
   - 엔진 버전이 다르다고 나오면 `ProjectB.uproject` 우클릭 → Switch Unreal Engine version → 설치된 버전 선택
3. 에디터가 열리면 상단 **Play** 버튼. 게임 화면이 뜨면 Enter로 시작

### macOS
1. Xcode 설치 (엔진 버전이 요구하는 버전)
2. `ProjectB.uproject`를 더블클릭 → 빌드 확인에서 **예**
   - 안 되면 엔진 폴더의 `Engine/Build/BatchFiles/Mac/GenerateProjectFiles.sh -project="<경로>/ProjectB.uproject" -game` 실행 후 Xcode로 빌드
3. Play

빌드 오류가 나면 출력 로그(Output Log)의 첫 번째 error 줄을 알려주면 된다.

## 2. 구조

```
ProjectB.uproject              엔진 버전 5.7로 지정 (다르면 바꿔도 됨)
Config/                        시작 맵(/Engine/Maps/Entry), 게임 모드, 해상도 1280x720
Source/ProjectB/
  TPCore.h / .cpp              규칙 코어: 판, 카드, 블록, 족보 판정, 연쇄, 라운드 (언리얼 의존성 없는 순수 C++)
  TPBoardWidget.h / .cpp       Slate 위젯: 그리기, 키 입력
  TPGameMode.h / .cpp          게임 시작 시 위젯을 화면에 붙임
  ProjectB.cpp, *.Build.cs     모듈 정의
Tests/
  core_test.cpp, run.sh        규칙 코어 시험 (언리얼 없이 g++로 실행)
```

| 결정 | 이유 |
|---|---|
| 규칙 코어를 순수 C++로 분리 | 언리얼 없이 시험 가능. 웹 프로토타입과 같은 결과가 나오는지 봇으로 확인 |
| 화면을 Slate로 직접 그림 (UMG, 머티리얼 없음) | 에셋 파일 없이 코드만으로 완결. 네온 선 화풍은 선과 글자뿐이라 충분 |
| 무늬(♠♥♦♣)를 글꼴 대신 선으로 그림 | 기본 글꼴에 무늬 글자가 없을 수 있음. 네온 화풍에도 더 맞음 |
| 빛번짐은 선을 세 겹(넓고 옅게 → 가늘고 밝게) 겹쳐 흉내 | UI에는 후처리 블룸이 안 걸림 |
| 엔진 기본 빈 맵 사용 | 프로젝트 맵(.umap) 없이 실행 |
| 한글 문자열이 있는 TPBoardWidget.cpp는 UTF-8 BOM으로 저장 | Windows 컴파일러(MSVC)가 한글을 깨뜨리지 않게 |

## 3. 검증 상태

| 항목 | 상태 |
|---|---|
| 규칙 코어 | 이 저장소에서 g++, clang++로 컴파일, 경고를 오류로 취급. 단위 시험 21개 통과 (족보 11, 보스 규칙, 연쇄 스트레이트 5, 낙하, 2단계 연쇄 52 → 164, 회전, 블록 떨어뜨리기) |
| 봇 40판 | 5라운드 1, 6라운드 8, 7라운드 14, 8라운드 17. 웹 봇(5라운드 1, 6라운드 15, 7라운드 12, 8라운드 10, 전부 통과 2)과 비슷한 분포. 난수가 달라 판마다 결과는 다름 |
| 위젯·게임 모드 | 언리얼 헤더를 흉내 낸 가짜 헤더로 문법·타입 검사만 통과. **실제 언리얼 빌드와 실행은 아직 안 해 봄** (개발 컨테이너에 엔진 없음) |

처음 빌드할 때 예상되는 위험:
- 엔진 버전에 따라 Slate 함수 시그니처가 조금 다를 수 있음 (FVector2D와 FVector2f)
- 한글 글꼴: 엔진 기본 글꼴의 한글 대체 글꼴을 쓴다. 한글이 네모로 나오면 Noto Sans KR 같은 글꼴을 프로젝트에 넣어야 함
- 글자 위치·크기 미세 조정 필요 (웹 캔버스와 Slate 글꼴 측정 방식이 다름)
