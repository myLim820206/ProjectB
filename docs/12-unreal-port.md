# 12. 언리얼 프로젝트 (포커 디펜스)

포커 디펜스 웹 프로토타입(prototype/poker-defense, v1.3)을 언리얼 엔진 5.8 C++로 옮겼다. 콘텐츠 1차(웨이브 보상, 부적 18종, 와일드 카드, 새 적 3종, 보스 3종), 합성, 조커 포탑, 스킬 트리까지 들어 있다.
웹 프로토타입은 v1.3에서 멈췄고 이후 개발은 언리얼에서만 한다 (D-062).
맵, 블루프린트, 에셋 없이 **C++ 코드만으로** 실행된다. 화면과 이펙트는 Slate로 직접 그리고, 효과음은 코드로 합성한다.

이전에 옮겼던 테트리스 포커 언리얼 코드는 폐기했다 (2026-11-08, git 기록에 남아 있음). 효과음 합성기만 이름을 바꿔(PDSynth) 다시 쓴다.

## 1. 열어 보기

### Windows
1. Visual Studio 2022에 "C++를 사용한 게임 개발" 워크로드 설치
2. 예전 빌드 결과가 있으면 `Binaries/`, `Intermediate/` 폴더를 지운다 (테트리스 포커 클래스가 남아 있을 수 있음)
3. `ProjectB.uproject` 더블클릭 → "모듈을 다시 빌드할까요?"에서 **예**
   - 엔진 버전을 물으면 `ProjectB.uproject` 우클릭 → Switch Unreal Engine version → 5.8 선택
4. 에디터가 열리면 상단 **Play**. 제목 화면에서 Enter 또는 클릭

### macOS
1. Xcode 설치 (엔진 버전이 요구하는 버전)
2. `ProjectB.uproject` 더블클릭 → 빌드 확인에서 **예**
3. Play

빌드나 실행 오류가 나면 출력 로그(Output Log)의 첫 번째 error 줄, 크래시면 호출 스택을 알려주면 된다.

## 3. 타워 모양

화풍은 docs/15-art-style.md (웹 프로토타입 네온)를 따른다. 타워는 둥근 사각 틀 안에 숫자(위)와 작은 무늬 기호(아래). 무늬 기호는 실제 카드 무늬 모양(스페이드·하트·다이아·클로버)을 네온 선으로, 와일드는 별. 족보에 든 타워는 틀 안이 옅게 차오르며 숨쉰다.
빛번짐은 넓고 옅은 선 세 겹 + 가는 심으로 웹 캔버스의 shadowBlur 느낌을 흉내 낸다.

## 3-1. 이펙트

| 이펙트 | 언제 |
|---|---|
| 레이저 빔 + 총구 고리 + 피격 불꽃 | 타워가 쏠 때 (족보에 든 타워는 더 굵게) |
| 충격파 고리 + 불꽃 | 범위 공격 (♥, 플러시, 풀하우스) |
| 파편 폭발 + 고리 | 적 처치 (탱크는 화면 흔들림, 보스는 큰 폭발·섬광·흔들림) |
| 설치 고리 + 입자, 커졌다 줄어드는 타워 | 카드를 놓을 때 |
| 칸 섬광 + 위로 솟는 입자 + 큰 글자 | 족보 완성 (풀하우스 이상은 화면 섬광과 흔들림) |
| 번개 | 연쇄로 이어진 족보 사이에 계속 일렁임 |
| 숨쉬는 빛 | 족보에 든 타워 |
| 잔상 | 빠른 적과 보스 |
| 빨간 섬광 + 흔들림 | 적이 빠져나가 목숨을 잃을 때 |
| 배너 | 웨이브 시작 (보스 웨이브는 빨강), 웨이브 통과 |
| 길 위를 흐르는 빛 점, 격자 물결 | 항상 |
| 폭죽 | 15웨이브 전부 통과 |

빛번짐은 굵고 옅은 선 위에 가늘고 밝은 선을 겹쳐 흉내 낸다 (UI에는 후처리 블룸이 안 걸림). 파티클은 같은 층에 묶어 그려 빠르다.

## 4. 콘텐츠 (v1.3과 같음)
- 웨이브를 막으면 보상 3개 중 1개 (조커 2 + 즉시 1, 건너뛰기 가능). 조커 칸이 가득 차면 즉시 보상만
- 부적 18종 (최대 5칸): 무늬 애호가 4, 연결고리, 쌍둥이, 일직선, 넓은 물결, 그림 카드, 작은 수, 행운의 7, 큰 손, 보급, 재활용, 조준경, 서리, 연쇄 폭발, 관통탄
- 즉시 보상: 와일드 카드(흰 별 타워, 아무 숫자·무늬), 보충(2장), 수리(목숨 +3)
- 적: 보통, 빠름, 탱크, 방패병(한 방 피해 감소, 최소 25%), 분열체(죽으면 둘), 재생자(초당 3% 회복), 분열 조각
- 보스: 5 방패 거인, 10 분열 군주(탱크 넷으로), 15 재생 왕
- 화면: 보상 카드 3장, 조커 패널(오른쪽), 적마다 다른 도형, 방패 막대, 보스 이름 배너, 보상 획득 연출

- **합성 (v1.4)**: 족보 아래 [합성] 버튼 또는 G → 타워 하나로 합쳐 레벨 업(최대 4), 위력 합 × 1.5, 족보 효과가 영구 특성. 같은 레벨끼리만 족보
- **조커 포탑 (v1.5)**: 연쇄로 이어진 족보 3개(합성 타워 포함) → [조커] 버튼 → 조커 포탑 10종 (레시피별 능력, 와일드, 최종형). J 키 도감. 보상의 "조커"는 "부적"으로 이름 변경
- **무한 진행 (v1.4)**: 승리 없음, 15웨이브 뒤 적 체력 ×1.3씩, 보스 3종 반복, 덱이 비면 새 덱
- **스킬 트리 (v1.6~1.7, docs/16-skill-tree.md)**: 처치·웨이브 통과로 골드 → 포인트(20골드부터 ×1.22씩)로 노드를 찍는다. 판 안에서만 유지, 129노드 (큰길 + 막다른 주머니), 짝 키스톤 4쌍(하나 찍으면 짝 봉인, 최대 3개), 바깥 끝자락 조커 강화 10개는 서로 끊어져 있음. 배치 원본은 `tools/tree/gen_tree.py`
- **골드 강화 (v1.7)**: 공격·공격 속도·치명타 확률·치명타 배율·무늬 4종, 레벨 0~9999 (값 10 + 2 × 레벨). 치명타 기본 5% ×1.5, 100% 넘으면 한 방에 여러 번
- **족보 10개·대장 조커 (v1.7)**: 로열 스트레이트 플러시·파이브 카드 추가. 조커 = 재료 중 가장 높은 족보의 대장, 지휘(자기 족보 +30%, 겹침)

## 5. 조작
| 입력 | 동작 |
|---|---|
| 카드 클릭 / 숫자키 | 카드 고르기 (손패 최대 9장) |
| 칸 클릭 | 설치 (놓기 전에 생길 족보와 연쇄를 미리 보여 줌) |
| 오른쪽 클릭 (카드) | 버리기 |
| Space / Enter | 웨이브 시작 |
| 보상 화면: 1~3 / 클릭 / S | 보상 고르기 / 건너뛰기 |
| F | 속도 ×1 / ×2 / ×3 |
| [합성] 버튼 / G | 족보를 타워 하나로 합성 (G는 마우스가 올라간 족보) |
| [조커] 버튼 | 연쇄된 족보 3개 이상을 조커 포탑으로 |
| J | 조커 도감 |
| K / [트리] 버튼 | 스킬 트리 (여는 동안 멈춤, 노드 클릭으로 찍기) |
| U / [강화] 버튼 | 골드 강화 (여는 동안 멈춤, +1 / +10 / +100 / 최대) |
| Esc / M / R | 취소 / 소리 / 다시 시작 (게임 오버 후) |

## 6. 검증 상태

| 항목 | 상태 |
|---|---|
| 규칙 코어 | g++, clang++로 컴파일 (경고를 오류로). 단위 시험 88개 통과 (합성 3, 무한 진행 2, 조커·대장 9, 스킬 트리 20, 골드 강화 6 포함): 족보 16가지 (로열·파이브 카드 포함), ㄴ자 플러시, 연쇄, 풀하우스 우선, 떨어진 족보, 트리플 우선, 무작위 길 200개, 설치·교체, 와일드 카드, 방패·관통탄, 분열, 재생, 조커 효과, 보상 후보, 큰 손, 와일드 보상, 덱 52장 중복 없음 |
| 트리 봇 10판 | 합성·조커·트리 평균 23.1웨이브, 판당 17.5포인트 (트리 없이 18.7). docs/16 6절 |
| 봇 10판 (적 체력 웨이브마다 ×1.45) | 족보 생각 + 조커 먼저 6판 통과·4판 15웨이브 실패 / 족보 생각 + 보상 안 받음 1판 통과 / 족보 무시 + 조커 전부 9~13웨이브 실패 |
| 위젯·게임 모드 | 언리얼 헤더를 흉내 낸 가짜 헤더로 문법·타입·가림 경고 검사만 통과. **실제 언리얼 빌드와 화면은 아직 확인 못 함** (개발 컨테이너에 엔진 없음). 그리기 도우미와 게임 모드는 테트리스 포커 때 5.8에서 빌드·실행된 코드를 그대로 썼다 |
