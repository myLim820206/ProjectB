# 08. 튜토리얼, 결말, 칭호

## 1. 도입

서장 장면 P-01 ([대본](../scenario/P-01-prologue.md)): 월향의 편지, 고갯길, 낡은 주막. 순덕 할매가 말을 걸고 첫날 새벽 준비로 이어진다.

## 2. 튜토리얼 (1~3일차)

| 날 | 가르치는 것 | 제한 |
|---|---|---|
| 1일차 | 장국밥 한 솥 끓이기, 손님 클릭해서 차려 내기, 빈 그릇 치우기, 계산 | 메뉴 1개, 손님 6명, 인내심 감소 없음 |
| 2일차 | 번철로 파전 굽기, 타는 시간, 막걸리 따르기, 차림표 정하기 | 메뉴 3개, 손님 10명 |
| 3일차 (장날) | 장보기와 신선도, 손님 취향, 인내심, 장부 보기, 첫 상환 일정 안내 | 제한 해제 |

- 설명은 순덕 할매와 김 서방이 대화로 알려 준다. 한 번에 한 가지만
- 튜토리얼 안내는 설정에서 다시 볼 수 있다
- 2단계 도달(보통 6~7일차) 때 일꾼 고용 안내, 3단계 도달 때 밤 주막 해금 연출

## 3. 결말

결말은 하나다. 갈래 엔딩 대신 칭호로 플레이를 평가한다.

| 항목 | 규칙 |
|---|---|
| 조건 | 빚을 다 갚은 날 (마지막 상환 또는 밀린 빚 완납) |
| 시점 | 빚 미리 갚기는 다음 회차 금액까지만 가능하므로 빨라도 80일차. 늦게 갚으면 그만큼 늦게 |
| 장면 | E-01 보름달 잔치 (그림 두루마리), 월향의 마지막 편지, 칭호 카드 |
| 실패 | 없음. 기간 제한도 없다. 80일 이후에도 남은 빚을 갚으며 계속 영업한다 |
| 이후 | 결말 뒤에도 계속 영업 가능 (자유 영업). 지역 시나리오 해금 |

이야기 흐름은 [09-scenario.md](09-scenario.md) 참고.

## 3.1 칭호

결말 장면 끝에 칭호 카드를 보여 준다. 기준 데이터: [`data/titles.csv`](../../data/titles.csv)

- **대표 칭호 1개**: 결말 시점 평판 단계로 정한다

| 대표 칭호 | 조건 |
|---|---|
| 팔도 제일 주막 | 평판 5단계 |
| 이름난 주막 | 평판 4단계 |
| 고을의 주막 | 평판 3단계 |
| 정다운 동네 주막 | 그 외 |

- **덧붙는 칭호 여러 개**: 조건을 만족한 것을 모두 붙인다

| 칭호 | 조건 |
|---|---|
| 요괴들의 벗 | 요괴 하나와 친밀도 100 |
| 달빛 아래 주인장 | 요괴 친밀도 합계 300 이상 |
| 단골 부자 | 단골 이야기 8명 이상 완료 |
| 빚 한 푼 안 밀린 주인 | 상환 실패 0회 |
| 장맛의 달인 | 장 보정 +2 요리 300그릇 |
| 술도가 명인 | 품질 5 술 300사발 |
| 길손의 쉼터 | 객방 3단계 |
| 느긋한 주인장 | 느긋한 모드로 결말 |
| 천천히 걸어온 길 | 100일차 이후 결말 |

- 칭호 문구는 모두 긍정적으로 쓴다. 늦게 갚거나 느긋한 모드로 끝낸 플레이어에게도 칭찬이 돌아간다
- 칭호는 Steam 도전과제와 1:1로 연결한다
- 칭호 도감: 얻은 칭호를 타이틀 화면에 기록. 자유 영업 중 새 조건을 만족하면 추가로 얻을 수 있다

## 4. 지역 시나리오 (엔딩 후 해금)

| 지역 | 해금 | 특징 |
|---|---|---|
| 고갯길 주막 | 본편 | 기본 지역. 보부상, 나그네 중심 |
| 나루터 주막 | 결말 | 어물이 싸고 다양함. 사공과 상인 손님. 물귀신 자주 등장. 비 오는 날 손님 감소가 적음 |
| 장터 주막 | 대표 칭호 이름난 주막 이상 | 매일이 장날 수준으로 손님이 많지만 인내심이 짧음. 경쟁 주막 이벤트 |

- 지역 시나리오는 빚 대신 지역별 목표가 있고, 목표를 이루면 짧은 지역 결말과 칭호 (예: 나루터 주막은 "물귀신 친밀도 100")
- 출시 범위: 본편 + 나루터 주막. 장터 주막은 업데이트 후보
