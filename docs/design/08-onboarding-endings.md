# 08. 튜토리얼과 엔딩

## 1. 도입

1. 짧은 그림 두루마리 연출: 돌아가신 친척의 편지, 낡은 주막, 빚 문서
2. 주막 마당에 도착. 이웃 두부집 할매(단골)가 말을 건다
3. 첫날 새벽 준비부터 시작

## 2. 튜토리얼 (1~3일차)

| 날 | 가르치는 것 | 제한 |
|---|---|---|
| 1일차 | 장국밥 한 솥 끓이기, 손님 클릭해서 차려 내기, 빈 그릇 치우기, 계산 | 메뉴 1개, 손님 6명, 인내심 감소 없음 |
| 2일차 | 번철로 파전 굽기, 타는 시간, 막걸리 따르기, 차림표 정하기 | 메뉴 3개, 손님 10명 |
| 3일차 (장날) | 장보기와 신선도, 손님 취향, 인내심, 장부 보기, 첫 상환 일정 안내 | 제한 해제 |

- 설명은 두부집 할매와 김 서방이 대화로 알려 준다. 한 번에 한 가지만
- 튜토리얼 안내는 설정에서 다시 볼 수 있다
- 2단계 도달(보통 6~7일차) 때 일꾼 고용 안내, 3단계 도달 때 밤 주막 해금 연출

## 3. 엔딩

본편 80일차 마감 정산 후 결과에 따라 엔딩을 고른다. 위에서부터 조건을 확인한다.

| 엔딩 | 조건 | 내용 |
|---|---|---|
| 팔도 제일 주막 | 빚 전액 상환, 평판 5단계, 요괴 친밀도 100 하나 이상 | 사람과 요괴 모두에게 소문난 주막. 그림 두루마리 엔딩 |
| 이름난 주막 | 빚 전액 상환, 평판 4단계 이상 | 고을에서 손꼽히는 주막 |
| 요괴들의 단골집 | 요괴 친밀도 합계 300 이상 (빚과 무관) | 사람들은 모르지만 밤마다 북적이는 주막 |
| 소박한 동네 주막 | 빚 전액 상환 | 크지 않아도 정다운 주막 |
| 빚은 남았지만 | 위 조건 모두 아님 | 빚쟁이가 찾아오지만 단골들이 십시일반 도와주는 따뜻한 마무리. 실패가 아니라 다음 이야기를 암시 |

- 엔딩 후 이어 하기: 80일 이후에도 계속 영업 가능 (자유 영업 모드, 빚과 엔딩 없음)
- 엔딩 도감: 본 엔딩을 타이틀 화면에 기록

## 4. 지역 시나리오 (엔딩 후 해금)

| 지역 | 해금 | 특징 |
|---|---|---|
| 고갯길 주막 | 본편 | 기본 지역. 보부상, 나그네 중심 |
| 나루터 주막 | 아무 엔딩 | 어물이 싸고 다양함. 사공과 상인 손님. 물귀신 자주 등장. 비 오는 날 손님 감소가 적음 |
| 장터 주막 | 이름난 주막 이상 엔딩 | 매일이 장날 수준으로 손님이 많지만 인내심이 짧음. 경쟁 주막 이벤트 |

- 지역 시나리오는 본편과 같은 80일 구조. 빚 대신 지역별 목표 (예: 나루터 주막은 "물귀신 친밀도 100")
- 출시 범위: 본편 + 나루터 주막. 장터 주막은 업데이트 후보
