# 01. 시간과 하루 흐름

## 1. 시간 단위

| 단위 | 길이 |
|---|---|
| 게임 1시간 (낮) | 실시간 25초 |
| 낮 영업 | 게임 06시 ~ 18시, 실시간 300초 |
| 밤 영업 | 게임 19시 ~ 24시, 실시간 125초 |
| 하루 | 실시간 약 6~8분 (준비와 정산 시간 제외) |
| 계절 | 10일 |
| 1년 | 4계절, 40일 |
| 본편 | 2년, 80일 |

## 2. 하루 상태 흐름

```
새벽 준비 ──▶ 낮 영업 ──▶ 해질녘 전환 ──▶ 밤 영업 ──▶ 마감 정산 ──▶ 저장 ──▶ 다음 날 새벽
                              │              (해금 후)        ▲
                              └───────── 밤 영업 미해금 ───────┘
```

| 상태 | 시간 흐름 | 가능한 행동 | 종료 조건 |
|---|---|---|---|
| 새벽 준비 | 정지 | 장보기, 차림표 정하기, 솥 미리 끓이기, 술과 장 담그기, 일꾼 배치 | "문 열기" 버튼 |
| 낮 영업 | 흐름 | 조리, 서빙, 치우기. 건설 불가 | 18시 도달 후 남은 손님이 모두 떠남 |
| 해질녘 전환 | 연출 5초 | 없음. 초롱이 켜지는 연출 | 자동 |
| 밤 영업 | 흐름 | 낮과 같음 | 24시 도달 후 남은 손님이 모두 떠남 |
| 마감 정산 | 정지 | 장부 확인, 건설과 확장, 꾸미기, 일꾼 고용 | "잠자리에 들기" 버튼 |
| 저장 | 자동 | 없음 | 자동 |

- 18시가 되면 새 손님은 오지 않는다. 이미 앉은 손님은 끝까지 응대할 수 있다
- 영업 종료 직후 남은 솥 요리는 버려진다 (03-cooking 참고)

## 3. 속도와 일시정지

| 기능 | 규칙 |
|---|---|
| 배속 | 영업 중 1배속, 2배속 |
| 일시정지 | 언제든 가능. 일시정지 중에는 조작 불가 (메뉴와 정보 확인만) |
| 느긋한 모드 | 설정 옵션. 손님 인내심이 줄어드는 속도 50%. 언제든 켜고 끌 수 있다 |

## 4. 달력

### 4.1 장날 (5일장)
- 각 계절 1일과 6일이 장날이다
- 장날 효과: 손님 1.5배, 농부 2배, 장터 품목 증가, 새 일꾼 후보 등장

### 4.2 계절 행사
| 계절 | 날 | 행사 | 효과 |
|---|---|---|---|
| 봄 | 3일 | 삼짇날 | 화전 수요 증가, 진달래 저렴 |
| 여름 | 5일 | 단오 | 손님 증가, 특별 손님 확률 증가 |
| 가을 | 3~7일 | 과거 시험 철 | 선비 3배 |
| 가을 | 8일 | 추석 | 인절미 해금, 손님 증가 |
| 겨울 | 5일 | 동지 | 따뜻한 국 수요 증가 |
| 겨울 | 10일 | 설 | 한 해 결산 연출, 단골 방문 확률 증가 |

### 4.3 날씨
| 계절 | 비 또는 눈 확률 | 효과 |
|---|---|---|
| 봄 | 20% (비) | 손님 0.7배, 평상 좌석 절반만 사용 |
| 여름 | 35% (비) | 같음. 국밥 대신 냉국 선호 증가 |
| 가을 | 15% (비) | 같음 |
| 겨울 | 30% (눈) | 손님 0.7배, 평상 절반. 따뜻한 국 선호 증가 |

툇마루와 마루방은 날씨와 무관하게 쓸 수 있다. 날씨는 전날 정산 화면에서 예보로 알려 준다 (적중률 80%) `[조정]`.

## 5. 저장

- 자동 저장: 매일 새벽 준비 시작 시점
- 수동 저장 슬롯 3개. 새벽 준비와 마감 정산 중에만 저장 가능
- 영업 도중 종료하면 그날 새벽 준비부터 다시 시작
- 저장 데이터에는 버전 필드를 둔다 (02 기술 계획 9절)
