# 02. 영업

## 1. 손님 흐름

```
도착 ─▶ 자리 있음? ─예─▶ 착석 ─▶ 주문(2초) ─▶ 음식 대기 ─▶ 식사 ─▶ 계산 ─▶ 떠남 ─▶ 빈 그릇 남음
          │                                   │
          아니오                              인내심 0
          ▼                                   ▼
       문 앞 대기 (최대 10초) ─▶ 떠남        화내며 떠남
```

| 상태 | 인내심 감소 | 비고 |
|---|---|---|
| 문 앞 대기 | 1.5배 | 10초 안에 자리가 안 나면 그냥 지나침 |
| 주문 | 없음 | 2초 동안 말풍선 생성 연출 |
| 음식 대기 | 1배 | 음식이 일부만 나와도 감소 계속 |
| 식사 | 정지 | 8~12초 |
| 계산 | 없음 | 자동. 엽전이 상 위에 놓였다가 자동으로 걷힌다 |

- 일행(1~3명)은 한 좌석 묶음(평상 1개 등)에 함께 앉는다. 묶음에 빈자리가 모자라면 앉지 못한다
- 일행 각자가 주문한다. 음식 1개 + 확률(DrinkChance)로 술이나 음료 1개
- 포장 손님(아이 심부름)은 자리에 앉지 않고 부엌 앞에서 기다린다

## 2. 플레이어 조작 (클릭 운영형)

| 조작 | 결과 |
|---|---|
| 조리 시설 클릭 | 그 시설에서 만들 수 있는 주문 대기 음식 중 가장 오래 기다린 것부터 조리 시작. 여러 종류면 작은 선택 창 |
| 가마솥, 시루 클릭 | 미리 만든 음식을 한 그릇 떠서 차림 칸에 올림 (0.5초) |
| 술독 클릭 | 한 사발 따라 차림 칸에 올림 (0.5초) |
| 완성된 음식 클릭 (번철, 화로, 도마) | 차림 칸에 올림 |
| 손님 클릭 | 차림 칸에 그 손님 주문과 맞는 음식이 있으면 차려 냄 |
| 빈 그릇 클릭 | 치움 (1초). 치우기 전에는 그 자리에 새 손님이 못 앉음 |

- 차림 칸: 부엌 앞 상. 기본 4칸, 부엌 단계마다 2칸 추가
- 잘못 차리는 실수는 없다. 손님을 클릭하면 맞는 음식만 나간다 (코지 기조)
- 대신 시간과 순서 관리가 실력이다: 무엇을 먼저 굽고, 어느 손님을 먼저 챙기는가

### 2.1 타는 음식
- 번철과 화로 요리는 완성 후 BurnWindowSec(4~5초) 안에 거둬야 한다
- 늦으면 탄 음식이 된다: 품질 −2. 차려 낼 수는 있다

## 3. 인내심

- 손님 유형별 PatienceSec (customers.csv)
- 머리 위 고리 모양 게이지. 색과 모양을 함께 바꿔 색약 플레이어도 구분 가능 (07-ui)
- 0이 되면 화내며 떠난다: 계산 없음, 평판 −3

## 4. 만족도

식사를 마친 손님마다 만족도 S(0~100)를 계산한다.

```
S = 맛 + 기다림 + 취향 + 분위기
맛     = 음식 품질(1~5) × 10                      (10 ~ 50)
기다림 = 30 × 음식이 나왔을 때 남은 인내심 비율      (0 ~ 30)
취향   = 선호 분류 20 / 보통 10                    (10 ~ 20)
분위기 = 주막 분위기 점수 / 10, 최대 10              (0 ~ 10)
```

- 일행 손님은 각자 계산한다. 음식과 술을 둘 다 시킨 손님은 두 음식 품질의 평균을 쓴다
- 금기 음식(스님에게 고기나 술)은 차림 단계에서 막는다. 해당 손님 주문 목록에 애초에 들어가지 않는다

| 등급 | 조건 | 평판 | 지불 |
|---|---|---|---|
| 최고 | S ≥ 85 | +3 | 값 + 팁 20% |
| 만족 | 65 ≤ S < 85 | +2 | 값 |
| 보통 | 40 ≤ S < 65 | +1 | 값 |
| 불만 | S < 40 | −1 | 값 |
| 화내며 떠남 | 인내심 0 | −3 | 없음 |
| 그냥 지나침 | 자리 없음 | −0.3 | 없음 |

평판 변화량에는 소문력 배수를 곱한다: `× (1 + 0.25 × (Rumor − 1))`. 단, 감소량에는 곱하지 않는다.
평균적인 손님 1명이 주는 평판은 약 +2.2 (시뮬 상수 REP_PER_SERVED × RUMOR와 같은 수준)이다.

## 5. 손님 도착

### 5.1 하루 방문 기대 인원
```
기대 인원 = 12 × 평판 배수 × 날씨 × 장날 × (1 + 간판 보너스) × (1 + 0.15 × 호객꾼 수) × 행사 배수
```
- 평판 배수: reputation.csv의 ArrivalMult (1.0 ~ 2.6)
- 날씨: 맑음 1.0, 비나 눈 0.7
- 장날: 1.5
- 하루 실제 인원은 기대 인원의 ±15% 무작위

### 5.2 시간대 분포
| 게임 시각 | 가중치 |
|---|---|
| 06 ~ 08 | 0.6 |
| 08 ~ 11 | 0.8 |
| 11 ~ 13 (점심) | 1.6 |
| 13 ~ 16 | 0.8 |
| 16 ~ 18 (저녁) | 1.3 |

### 5.3 유형 선택
도착할 때마다 유형을 뽑는다: `SpawnWeight × Modifiers × (그 시간대에 나오는 유형인가) × (평판 단계 조건)`.
마루방이 없으면 양반은 나오지 않는다. 상세는 04-customers.

## 6. 일꾼

| 역할 | 자동으로 하는 일 | 처리 속도 |
|---|---|---|
| 찬모 | 배치된 조리 시설에서 주문 대기 음식을 조리하고 차림 칸에 올림 | 솜씨에 따라 조리 시간 0.8 ~ 1.2배 |
| 심부름꾼 | 차림 칸 음식을 맞는 손님에게 차려 냄, 빈 그릇 치움 | 손빠르기에 따라 이동 속도 |
| 술도가 | 술독에서 술 따르기, 숙성 품질 +1 (상한 5) | |
| 호객꾼 | 하루 방문 인원 +15% | |

- 일꾼 1명은 대략 손님 2명/분을 처리하는 효과를 낸다. 플레이어(보통 4.2명/분)의 절반 수준 (시뮬 STAFF_THROUGHPUT)
- 플레이어 클릭이 언제나 일꾼보다 우선한다. 같은 일을 동시에 하려 하면 일꾼이 양보
- 일당 기본 35푼, 능력치에 따라 25 ~ 60푼. 마감 정산 때 자동 지급
- 피로: 매일 일하면 쌓이고, 휴무일을 지정하면 회복. 피로가 높으면 처리 속도 −20%
- 고용 상한: 일꾼방 없음 1명, 일꾼방 단계별 3 / 5 / 7명 (facilities.csv)

## 7. 영업 난이도 조절 장치

| 장치 | 효과 |
|---|---|
| 차림표 크기 | 메뉴가 적으면 조리가 단순, 많으면 손님 취향을 더 맞춤 |
| 느긋한 모드 | 인내심 감소 50% |
| 솥 미리 끓이기 | 영업 중 클릭 부담을 준비 단계로 옮김 |
| 일꾼 | 단계가 오를수록 플레이어 클릭 부담을 줄임 |
