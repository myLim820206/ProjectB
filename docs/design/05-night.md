# 05. 밤 주막

## 1. 해금

1. 평판 3단계에 도달한 날 마감 정산에서 "밤에 문 두드리는 소리가 난다"는 예고가 뜬다
2. 다음 날 해질녘 전환 후, 도깨비 하나가 찾아와 막걸리 한 사발을 청한다 (튜토리얼 손님, 실패 없음)
3. 도깨비가 "이 길목은 원래 우리가 다니는 길"이라며 다른 요괴들에게 소문을 내겠다고 한다
4. 다음 날부터 밤 영업이 열린다. 메밀묵 레시피와 메밀이 해금된다

보통 플레이 기준 해금 시점: 21일차 전후 (1년차 가을 초). 시뮬 결과는 06-progression-economy 참고.

## 2. 밤 영업 규칙

| 항목 | 규칙 |
|---|---|
| 시간 | 게임 19시 ~ 24시, 실시간 125초 |
| 손님 수 | 하루 최대 `3 + 평판 단계` 마리. 밝힌 좌석 수와 처리 능력으로 제한 |
| 밝힌 좌석 | 주등과 간판 단계별 4 / 8 / 전부. 밝히지 않은 자리에는 앉지 않는다 |
| 차림표 | 낮 차림표를 그대로 쓴다. 남은 솥 요리는 밤까지 유지되고 밤 영업이 끝나면 버린다 |
| 일꾼 | 밤에도 일한다. 피로가 1.5배 쌓인다 |
| 평판 | 요괴 손님 1마리당 평판 +2. 요괴들의 소문이 사람 사이로도 퍼진다는 설정 |

- 달걀귀신은 얼굴이 없어 인내심 게이지가 보이지 않는다. 대신 몸이 점점 떨리는 연출 (난이도 장치)

## 4. 장난

- 불만 또는 화내며 떠난 요괴는 확률 `PrankChance × (1 − 금줄 감소율)`로 장난을 친다
- 금줄 30%, 성황당 60% 감소

| 장난 | 효과 |
|---|---|
| 그릇 깨기 | 차림 칸 음식 1개 사라짐 |
| 재료 훔치기 | 무작위 재료 3개 사라짐 |
| 술 쉬게 하기 | 무작위 술독 하나가 다음 날 쉼 상태로 앞당겨짐 |
| 솥 뒤엎기 | 남은 솥 요리 전부 사라짐 (도깨비만) |

평균 손실은 약 30푼으로 잡는다 (시뮬 PRANK_LOSS). 무섭기보다 해학적으로 연출한다: 깨진 그릇 조각 사이로 도깨비 발자국이 남는 식.

## 5. 친밀도

- 요괴 종류마다 친밀도 0~100
- 변화: 최고 +8, 만족 +5, 보통 +2, 불만 −3, 화내며 떠남 −6
- 30: 그 요괴의 이야기 1장. 60: 이야기 2장과 특별 선물. 100: 이야기 3장, 엔딩 조건에 반영
