# 07. UI

## 1. 화면 흐름

```
타이틀 ─▶ 저장 슬롯 선택 ─▶ (새 게임) 도입 연출 ─▶ 주막 화면
                                                    │
        ┌──────────────── 새벽 준비 ──────────────────┤
        │  장터 / 차림표 / 솥 끓이기 / 술·장 담그기 / 일꾼 배치
        │
        ├──────────────── 영업 (낮, 밤) ──────────────┤
        │  주막 화면 + 영업 HUD
        │
        └──────────────── 마감 정산 ─────────────────┘
           장부 / 단골 이야기 / 건설·꾸미기 / 일꾼 명부 / 저장

어디서나: 손님 수첩, 레시피 책, 설정, 일시정지 메뉴
```

## 2. 영업 HUD

```
┌───────────────────────────────────────────────────────────┐
│ [시계 두루마리 11시]   [엽전 12냥 30푼]   [평판 ■■■■□ 2단계] │
│                                                           │
│                 (쿼터뷰 주막 디오라마)                      │
│            손님 머리 위: 주문 말풍선 + 인내심 고리            │
│                                                           │
│ [차림 칸: □ □ □ □]                    [일시정지][1x][2x]   │
└───────────────────────────────────────────────────────────┘
```

| 요소 | 내용 |
|---|---|
| 시계 | 해와 달이 도는 두루마리. 18시 30초 전에 마감 예고 |
| 엽전 | 계산이 들어올 때마다 엽전 떨어지는 소리와 숫자 올라가는 연출 |
| 평판 | 다음 단계까지 진행 막대 |
| 주문 말풍선 | 음식 아이콘. 일행은 말풍선 하나에 여러 아이콘 |
| 인내심 고리 | 초록 원 → 노랑 반원 → 빨강 깜빡임. 색과 함께 모양과 깜빡임으로 구분 |
| 차림 칸 | 부엌 앞 상. 올라간 음식 아이콘 |
| 조리 진행 | 시설 위 진행 원. 완성되면 김이 오르고, 타기 직전 빨갛게 깜빡임 |

## 3. 화면별 요소

| 화면 | 요소 |
|---|---|
| 장터 | 상인별 탭, 품목 카드(값, 신선도 수명, 오늘 시세 화살표), 장바구니, 지난 7일 판매량 참고 |
| 차림표 | 해금 레시피 목록, 오늘 차림 칸 (기본 4개), 재료 충분 여부 표시, 계절 추천 표시 |
| 솥 끓이기 | 가마솥과 시루별 메뉴 선택, 그릇 수, 재료비 미리보기 |
| 술·장 담그기 | 술독과 장독 칸, 숙성 진행 막대, 최고 품질 예정일 |
| 장부 | 오늘 매출, 재료비, 일당, 남은 음식 손실, 순이익. 빚 상환 일정과 남은 빚. 지난 7일 그래프 |
| 건설·꾸미기 | 부지 격자, 시설 목록(비용, 필요 단계, 효과), 배치 미리보기, 90도 회전 |
| 일꾼 명부 | 일꾼 카드(능력치, 피로, 일당), 역할과 시설 배치, 휴무일, 장날 후보 고용 |
| 손님 수첩 | 손님 유형 도감, 단골 이야기 진행, 요괴 도감과 친밀도 |
| 레시피 책 | 해금한 레시피, 재료, 값, 해금 힌트 (미해금은 실루엣) |

## 4. 시각 언어

- 패널: 한지 질감 바탕, 먹 테두리
- 제목과 숫자: 붓글씨 느낌 서체 (상업용 무료 한글 서체로 결정)
- 확인과 결재: 붉은 낙관 도장을 찍는 연출
- 정산: 주판 알이 움직이고 장부를 넘기는 연출
- 강조색은 단청 램프에서만 가져온다 (07 아트 파이프라인)

## 5. 입력

| 동작 | 마우스, 키보드 | 게임패드 |
|---|---|---|
| 선택, 조리, 서빙 | 왼쪽 클릭 | A (커서 이동은 왼쪽 스틱, 대상 자동 맞춤) |
| 취소, 닫기 | 오른쪽 클릭, Esc | B |
| 카메라 이동 | 가장자리 스크롤, WASD | 오른쪽 스틱 |
| 카메라 회전 | Q, E | LB, RB |
| 확대, 축소 | 휠 | LT, RT |
| 일시정지 | Space | 시작 버튼 |
| 배속 | Tab | Y |

- 게임패드는 커서가 가까운 상호작용 대상에 달라붙는 방식으로 클릭 조작을 대신한다
- macOS: 오른쪽 클릭이 없는 트랙패드 사용자를 위해 Control+클릭을 취소로 인식

## 6. 접근성과 설정

| 항목 | 내용 |
|---|---|
| 느긋한 모드 | 인내심 감소 50% |
| 글자 크기 | 3단계 |
| 색 구분 | 인내심과 품질 표시는 색 + 모양 + 숫자 옵션 |
| 화면 흔들림, 깜빡임 | 끄기 가능 |
| 자막 | 대사는 모두 글자 (음성 없음) |
| 조작 변경 | 키 재배치 |

## 7. 현지화

- 모든 문자열은 언리얼 현지화 시스템(String Table)으로 관리한다
- 음식, 관직, 요괴 이름의 영어 표기 원칙: 고유 이름은 로마자 표기 + 짧은 설명 (예: Gukbap, rice soup)
- 한글 서체와 라틴 서체를 함께 지원하는 글꼴 조합을 정한다
