## 3. 미결정 사항 (우선순위 순)

| 번호 | 항목 | 왜 중요한가 | 결정 기한 |
|---|---|---|---|
| 1 | 게임 장르와 핵심 콘셉트 | 이후 모든 기획과 기술 선택의 기준 | 다음 기획 회의 |
| 2 | 시점 (사이드뷰 / 탑다운 / 쿼터뷰) | 카메라, 레벨 구조 결정 | 콘셉트 확정 직후 |
| 3 | 주 개발 언어 비중 (Blueprint / C++) | 프로젝트 구조와 코딩 규칙 | 골격 생성 전 |
| 4 | 공용 팔레트와 스프라이트 규격 | 모든 에셋의 일관성 | 프로토타입 전 |
| 5 | 목표 출시 시기 | 로드맵 역산 | 로드맵 작성 전 |
| 6 | 지원 언어 (한국어, 영어 등) | 현지화 구조를 초기에 넣을지 결정 | 프로토타입 전 |
| 7 | 정확한 가격 티어 | 스토어 설정과 수익 계산 | 베타 전 |

## 4. 목표

- 1차 목표: 핵심 재미를 검증하는 플레이 가능한 프로토타입
- 2차 목표: Windows와 macOS 양쪽에서 동일하게 동작하는 수직 슬라이스
- 최종 목표: Steam 정식 출시

## 5. 1인 개발 제약 조건

이 프로젝트의 모든 기획은 아래 제약을 통과해야 합니다.

| 제약 | 기준 |
|---|---|
| 개발 기간 | 프로토타입 포함 총 개발 기간을 짧게 잡고, 범위가 넘치면 기능을 빼지 기간을 늘리지 않는다 |
| 아트 | Claude가 코드로 생성 가능한 범위. 캐릭터와 애니메이션 최소화, 절차 생성 변형 활용 |
| 시스템 수 | 핵심 시스템 3개 이내. 나머지는 콘텐츠 반복으로 분량 확보 |
| 반복성 | 짧은 판(1~20분)을 반복하는 구조 필수. 단판성 선형 게임은 제외 |
| 가격 정당성 | 2,000원 ~ 5,000원에서 환불 없이 만족할 분량과 완성도 |

## 6. 범위 밖 (현재 기준)

- 온라인 멀티플레이, 로컬 멀티플레이
- 콘솔 (PlayStation, Xbox, Switch)
- 모바일
- Linux 네이티브 빌드 (Steam Deck은 Proton 호환 여부만 확인)

위 항목은 출시 후 확장 후보로 남겨 둡니다.

| 단계 | 기준 |
|---|---|
