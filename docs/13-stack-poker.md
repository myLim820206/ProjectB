# 13. 스택 포커 (가제)

참고작: 액션퍼즐패밀리의 3줄 쌓기 모드 (위에 매달린 블록 줄에 아래에서 블록을 쏘아 같은 색을 맞춤).
사용자 방향: 색 맞추기 대신 카드 족보로.

프로토타입: [prototype/stack-poker](../prototype/stack-poker/README.md)

## 설계 결정 (초안)
| 결정 | 이유 |
|---|---|
| 줄 맨 아래 3~5장만 판정, 순서 상관없음 | 쏘는 순간 "이 줄에 넣으면 뭐가 되나"만 보면 됨. 순서까지 따지면 너무 어려움 |
| 원 페어 안 터짐, 투 페어부터 | 테트리스 포커와 같은 기준. 페어는 노란 선으로 준비 표시 |
| 스트레이트는 4장, 플러시는 5장 | 3장 스트레이트·플러시는 너무 쉽게 터짐 |
| 조커 (원작의 BONUS 블록 자리) | 막힌 줄을 푸는 구원 카드 |
| 경고선에 닿으면 게임 오버 대신 줄 폭발 + 시간 -8초 | 시간제 점수 모드라 흐름을 끊지 않음 |
| 다음 카드와 바꾸기 허용 | 운 요소 완화 |
| 90초 시간제 점수 | 원작 화면의 시간 막대 + 점수 구조 |

## 테트리스 포커와 비교
| | 테트리스 포커 | 스택 포커 |
|---|---|---|
| 조작 | 블록 이동·회전·낙하 | 줄 선택 + 쏘기 (한 번의 선택) |
| 판정 | 판 위 붙은 카드 덩어리 | 줄 맨 아래 n장 |
| 연쇄 | 받침 없는 카드가 떨어져서 | 거의 없음 (터진 뒤 남은 아래 카드가 또 족보일 때) |
| 압박 | 블록 수 제한 + 목표 점수 | 시간 + 밀려 내려오는 카드 |
| 모바일 | 어려움 | 쉬움 (줄을 누르면 끝) |

## 열린 질문
- 연쇄를 키울 방법: 터지면 옆 줄 맨 아래 카드도 검사, 또는 터진 줄이 끌어올려지며 위 카드와 맞으면 터짐
- 라운드·목표 점수와 규칙 카드(docs/11)를 붙일지, 시간제 점수 모드로 갈지
- 줄 수 (3줄 vs 4줄), 카드가 밀려 내려오는 속도
