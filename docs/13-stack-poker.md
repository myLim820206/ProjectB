# 13. 스택 포커 (가제)

참고작: 액션퍼즐패밀리의 3줄 쌓기 모드 (위에 매달린 블록 줄에 아래에서 블록을 쏘아 같은 색을 맞춤).
사용자 방향: 색 맞추기 대신 카드 족보로.

프로토타입: [prototype/stack-poker](../prototype/stack-poker/README.md)

## 설계 결정 (초안)
| 결정 | 이유 |
|---|---|
| 줄 맨 아래 3~5장만 판정, 순서 상관없음 | 쏘는 순간 "이 줄에 넣으면 뭐가 되나"만 보면 됨. 순서까지 따지면 너무 어려움 |
| 원 페어 안 터짐, 투 페어부터 | 테트리스 포커와 같은 기준. 페어는 노란 선으로 준비 표시 |
| 스트레이트는 4장, 플러시는 5장 | 3장 스트레이트·플러시는 너무 쉽게 터짐 |
| 조커 (원작의 BONUS 블록 자리) | 막힌 줄을 푸는 구원 카드 |
| 경고선에 닿으면 게임 오버 대신 줄 폭발 + 시간 -8초 | 시간제 점수 모드라 흐름을 끊지 않음 |
| 다음 카드와 바꾸기 허용 | 운 요소 완화 |
| 90초 시간제 점수 | 원작 화면의 시간 막대 + 점수 구조 |

## 테트리스 포커와 비교
| | 테트리스 포커 | 스택 포커 |
|---|---|---|
| 조작 | 블록 이동·회전·낙하 | 줄 선택 + 쏘기 (한 번의 선택) |
| 판정 | 판 위 붙은 카드 덩어리 | 줄 맨 아래 n장 |
| 연쇄 | 받침 없는 카드가 떨어져서 | 거의 없음 (터진 뒤 남은 아래 카드가 또 족보일 때) |
| 압박 | 블록 수 제한 + 목표 점수 | 시간 + 밀려 내려오는 카드 |
| 모바일 | 어려움 | 쉬움 (줄을 누르면 끝) |

## 열린 질문
- 연쇄를 키울 방법: 터지면 옆 줄 맨 아래 카드도 검사, 또는 터진 줄이 끌어올려지며 위 카드와 맞으면 터짐
- 라운드·목표 점수와 규칙 카드(docs/11)를 붙일지, 시간제 점수 모드로 갈지
- 줄 수 (3줄 vs 4줄), 카드가 밀려 내려오는 속도

## v2: 클릭해서 족보 만들기, 4줄

피드백: 쏘기보다 내려오는 패를 보고 클릭해서 족보를 만들고 싶다. 줄은 한 줄 늘리자.

| 결정 | 이유 |
|---|---|
| 쏘기 삭제, 카드 클릭으로 고르기 (여러 줄 섞어서, 최대 5장) | 사용자 요청. 판 전체를 훑어 족보를 찾는 눈 퍼즐로 바뀜 |
| 4줄 | 사용자 요청 |
| 아무 카드나 고를 수 있음 | 맨 아래 3장만 고르게 했더니, 새 카드가 위로 들어와 고를 구역에 오래 안 닿아 계속 막힘 (봇 18번 버리기) |
| 고른 카드 전부가 족보여야 함, 원 페어 안 됨 | 아무거나 섞어 내면 판단이 사라짐 |
| 터진 자리는 아래 카드가 위로 붙음 | 줄이 위에 매달린 구조 유지 |
| 콤보 창 5초, ×1.25씩 최대 ×3 | ×0.5씩 끝없이 오르면 빠른 사람과 느린 사람 점수 차가 너무 큼 |
| 카드 내려오는 속도: 처음 초당 약 1장 → 90초 무렵 약 2.2장 | 봇 기준 족보 하나에 3초 걸리면 줄 폭발 1.5번 |
| 버리기 (1~2장, 시간 -3초) | 막혔을 때 탈출구 |

### 원 페어 추가
피드백: 원 페어도 할 수 있어야 하지 않나?

| 결정 | 이유 |
|---|---|
| 원 페어 10 × 1 (가장 낮음) | 클릭 방식에서는 2장만 빨리 골라 줄을 정리하는 수단이 자연스러움 |
| 원 페어는 콤보 단계를 올리지 않고 콤보 시간만 이어줌 | 페어 연타로 콤보 ×3을 쉽게 쌓는 것 방지. 페어로 콤보를 이어가다 큰 족보로 터뜨리는 플레이 |

### 키보드 조작
피드백: 키보드로 조작할 수 있게.

| 결정 | 이유 |
|---|---|
| 방향키 커서 + Space 고르기 + Enter 내기 (Z/X도 같음), 1~4로 줄 바로 이동 | PC(Steam) 기본 조작. 마우스와 함께 쓸 수 있음 |
| 커서는 줄 맨 아래부터 몇 번째인지로 기억 | 위에서 카드가 밀려 와도 커서가 보던 카드에서 안 움직임 |
