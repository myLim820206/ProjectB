## 1. 콘셉트

### 1.1 한 줄 피치
> 조선의 길목에 있는 낡은 주막과 빚을 물려받았다. 낮에는 길손에게, 밤에는 요괴에게 밥과 술을 내어 주막을 팔도에 소문난 곳으로 키운다.

### 1.2 장르
경영 시뮬레이션 (가게 운영 + 요리 + 손님 응대)

### 1.3 가제
(미정)

### 1.4 세계관과 시작 상황
- 시대: 조선. 실존 인물과 실제 역사 사건은 직접 다루지 않는다
- 플레이어는 돌아가신 친척의 주막을 물려받는다. 건물은 낡았고, 선대가 남긴 빚이 있다
- 주막 자리는 예부터 요괴가 지나다니는 길목이라는 소문이 있다 (밤 주막 복선)
- 톤: 따뜻하고 편안한 분위기(코지)를 기본으로, 요괴 손님 이야기에서 약간의 신비로움과 해학 [확인 필요]

### 1.5 핵심 경험
- 작은 초가 주막이 북적이는 큰 주막으로 커 가는 성취감
- 개점 전 준비와 영업 중 순발력이 맞물려 하루 장사가 잘 풀릴 때의 쾌감
- 손님 취향을 맞춰 단골을 만들고 이야기를 듣는 재미
- 밤마다 어떤 요괴가 찾아올지 기대하는 마음

### 1.6 레퍼런스
| 게임 | 가져올 점 | 피할 점 |
|---|---|---|
| 카이로소프트 게임 (라면가게, 온천 등) | 작은 가게를 키우는 경영, 저가 대비 긴 플레이 | 단조로운 반복 |
| Coffee Talk | 손님 이야기가 쌓이는 정서 | 텍스트 과다 |
| Stardew Valley | 하루 단위 루프, 계절 변화, 편안한 분위기 | 범위 과다 |
| Diner Dash | 클릭으로 처리하는 영업의 순발력 | 스트레스가 큰 난이도 |
| Travellers Rest | 술 숙성, 가게 확장 | 복잡한 조작 |

### 1.7 타깃 플레이어
- 코지 게임과 가게 경영 게임을 좋아하는 PC 플레이어
- 한국 음식과 설화, 전통 문화에 관심 있는 국내외 플레이어
- 하루 장사 한두 번만 하고 끄는 짧은 플레이 패턴

### 1.8 가격과 분량
- 가격대: 2,000원 ~ 5,000원
- 본편: 게임 시간 2년, 약 8~10시간
- 반복 가치: 지역 시나리오, 레시피와 손님 도감 수집, 엔딩 여러 개

## 3. 자원

| 자원 | 설명 |
|---|---|
| 엽전 | 기본 화폐. 단위는 푼 (100푼 = 10전 = 1냥) |
| 빚 | 시작 시 300냥. 정해진 날마다 일부를 갚는다. 못 갚아도 게임이 끝나지는 않지만 평판과 엔딩에 영향 |
| 평판 | 손님 만족이 쌓여 오르는 단계 수치. 해금 조건 |
| 재료 | 신선도가 있다. 채소와 생선은 빨리 상하고, 곡물과 장류는 오래 간다 |
| 술 | 술독에서 여러 날 숙성. 오래 숙성할수록 품질과 값이 오른다 |
| 장 | 된장, 간장, 고추장. 장독대에서 계절 단위로 숙성. 국과 무침 요리의 맛을 올리는 장기 투자 |
| 요괴 물건 | 밤 손님이 엽전 대신 두고 가는 물건. 특수 시설과 비전 레시피에 쓴다 |

술과 장의 숙성은 이 게임의 한국적인 핵심 장치다. 오늘 담근 술과 장이 며칠 뒤, 몇 계절 뒤의 장사를 바꾼다.

## 4. 영업 시스템

### 4.1 손님 한 명의 흐름
1. 손님이 도착해 빈자리(평상, 툇마루, 마루방)에 앉는다. 자리가 없으면 잠시 기다리다 떠난다
2. 머리 위에 주문 말풍선이 뜬다. 오늘 차림표 안에서 취향에 맞게 고른다
3. 플레이어가 조리 시설을 클릭해 조리를 시작한다. 또는 미리 만들어 둔 음식을 바로 퍼 담는다
4. 완성된 음식을 손님에게 클릭해 차려 낸다
5. 손님이 먹고 계산한다. 맛, 기다린 시간, 취향 일치로 만족도가 정해진다
6. 만족도에 따라 값, 평판, 소문이 바뀐다. 아주 만족하면 단골 점수가 쌓인다

### 4.2 미리 만들기와 주문 조리
- 국밥, 장국 같은 솥 요리는 새벽에 한 솥 끓여 두면 영업 중에 바로 퍼 줄 수 있다. 대신 남으면 버린다
- 전, 구이는 주문마다 부친다. 맛은 좋지만 시간이 걸린다
- 오늘 손님이 얼마나 올지 예측해 솥 크기와 차림표를 정하는 것이 준비 단계의 핵심 판단이다

### 4.3 인내심과 실수
- 손님마다 인내심 게이지가 있다. 바닥나면 화를 내며 떠나고 평판이 떨어진다
- 잘못된 음식을 내면 만족도가 크게 떨어진다
- 영업 난이도는 손님 수로 조절한다. 코지 기조에 맞춰 실패해도 크게 벌받지 않게 한다

### 4.4 일꾼
| 역할 | 하는 일 | 주요 능력치 |
|---|---|---|
| 찬모 | 지정한 조리 시설에서 자동 조리 | 솜씨(맛), 손빠르기 |
| 심부름꾼 | 완성된 음식 서빙, 빈 그릇 치우기 | 손빠르기 |
| 술도가 | 술독과 장독 관리, 숙성 품질 향상 | 솜씨 |
| 호객꾼 | 길손 유입 증가 | 말솜씨 |

- 일꾼은 일당을 받는다. 일꾼방 크기가 고용 상한
- 초반은 플레이어가 모든 클릭을 하고, 일꾼을 들일수록 경영 판단에 집중하게 된다

## 6. 손님

### 6.1 낮 손님 유형
| 유형 | 예산 | 선호 | 특징 |
|---|---|---|---|
| 보부상 | 중 | 국밥, 막걸리 | 빨리 먹고 떠남. 소문을 멀리 퍼뜨림 |
| 농부 | 저 | 막걸리, 전 | 장날과 농한기에 많음 |
| 선비 | 중 | 약주, 전 | 오래 머묾. 과거 시험 철에 급증 |
| 포졸 | 중 | 국밥 | 점심 무렵 몰림 |
| 나그네 | 중 | 국밥 | 객방이 있으면 묵어 감 (숙박 수입) |
| 양반 | 고 | 고급 안주, 약주 | 마루방만 이용. 까다로움 |
| 스님 | 저 | 나물, 묵 | 고기 음식은 내면 안 됨 |
| 아이 심부름 | 저 | 국밥 포장 | 금방 떠남 |

손님 개체는 유형별 부위 조합(얼굴, 머리 모양, 갓이나 두건, 의복 색)으로 무작위 생성한다.

### 6.2 단골
- 같은 손님이 여러 번 만족하면 단골이 된다
- 단골은 개인 이야기를 조금씩 들려준다. 이야기 끝에 레시피, 일꾼 소개, 장식 같은 보상
- 출시 목표: 단골 이야기 10~12명

### 6.3 특별 손님 이벤트
| 이벤트 | 내용 |
|---|---|
| 암행어사 | 평범한 나그네로 위장해 온다. 단서로 알아채고 잘 대접하면 큰 평판 |
| 큰손 객주 | 대량 주문. 성공하면 큰돈과 거래처 |
| 미식가 양반 | 특정 요리의 품질을 평가. 장 숙성 품질이 중요 |
| 사또 행차 | 고을 수령의 방문. 대접 결과에 따라 세금 감면 또는 증가 |
| 광대패 | 마당에서 공연. 그날 손님 급증 |
| 소문난 술꾼 | 오래 숙성한 술을 찾아다님 |

## 7. 밤 주막 [가정]

### 7.1 해금
- 평판 3단계에 도달한 날 밤, 도깨비 하나가 찾아와 막걸리 한 사발을 청한다
- 대접하면 이후 밤 영업이 열린다. 이 길목이 요괴들이 지나다니는 길이었다는 소문이 사실로 드러난다

### 7.2 요괴 손님
| 요괴 | 좋아하는 것 | 내고 가는 것 | 특징 |
|---|---|---|---|
| 도깨비 | 메밀묵, 막걸리 | 도깨비 방망이 조각 | 기분이 좋으면 엽전을 두고 가기도 함. 씨름을 청하기도 |
| 구미호 | 고기 산적, 약주 | 여우 구슬 | 사람으로 둔갑해 낮에 섞여 오기도 함 |
| 물귀신 | 따뜻한 국밥 | 물에 젖은 엽전 | 추운 날 많이 옴 |
| 처녀귀신 | 화전, 약과 | 옛 노리개 | 사연을 들어 주면 성불하며 큰 보상 |
| 달걀귀신 | 달걀 요리 | 하얀 달걀껍질 부적 | 얼굴이 없어 표정을 읽기 어려움 |
| 장승 | 막걸리 (고사) | 마을 수호 효과 | 손님이라기보다 마을 행사 |

### 7.3 규칙
- 요괴는 엽전 대신 요괴 물건을 두고 간다. 요괴 물건은 비전 레시피, 특수 장식, 특수 시설에 쓴다
- 화가 난 요괴는 장난을 친다: 그릇 깨기, 재료 훔치기, 술독 쉬게 만들기
- 금줄, 부적, 성황당 시설로 장난을 줄일 수 있다
- 무섭기보다 해학적인 분위기로 연출한다

| 3 | 고을 주막 | 밤 영업, 화로, 객방 |
| 4 | 이름난 주막 | 특별 손님 이벤트 확대, 큰손 거래 |
| 5 | 팔도 제일 주막 | 최종 목표 |

## 10. 목표와 엔딩

- 본편 2년 동안 빚을 갚고 주막을 키운다. 실패로 게임이 끝나지는 않는다
- 엔딩은 빚 상환 여부, 평판 단계, 요괴들과의 관계로 갈린다 (예: 팔도 제일 주막, 요괴들의 단골 주막, 소박한 동네 주막)
- 엔딩 후 지역 시나리오가 열린다: 나루터 주막, 장터 주막. 지역마다 손님층, 재료, 목표가 다르다

## 11. 화면과 UI

- 요괴 일부(귀신, 도깨비불)는 걷기 대신 떠다니는 움직임을 코드로 준다

## 13. 범위 관리

| 구분 | 내용 |
|---|---|
| 반드시 있어야 하는 것 | 하루 루프 전체, 시설 10종 이상, 레시피 20종 이상, 낮 손님 6유형 이상, 술 숙성, 지역 1곳 |
| 있으면 좋은 것 | 밤 주막, 장 숙성, 단골 이야기, 특별 손님 이벤트, 지역 2~3곳 |
| 이번 버전에서 제외 | 걸어 다니는 주인 캐릭터, 넓은 마을 탐험, 연애 요소, 음성 연기, 멀티플레이 |

밤 주막은 차별화의 핵심이지만 범위 위험이 있어 "있으면 좋은 것"에 둔다. 낮 영업이 완성된 뒤 붙인다.

## 14. 프로토타입 범위 (M2)

하루 루프의 재미를 검증하는 최소 구성.

| 포함 | 제외 |
|---|---|
| 지역 1곳, 낮 영업만 | 밤 영업 |
| 시설: 가마솥, 번철, 도마, 술독, 평상 2개 | 건설과 확장 (고정 배치) |
| 레시피 5종: 장국밥, 파전, 두부김치, 막걸리, 콩나물국밥 | 장 숙성 |
| 낮 손님 3유형: 보부상, 농부, 선비 | 단골, 특별 손님 |
| 새벽 준비(장보기, 차림표, 미리 끓이기), 영업, 정산 | 일꾼 |
| 임시 아트 허용 (현재 생성기 수준) | 계절, 날씨 |

검증 질문:
1. 5분 영업 동안 클릭 조리와 서빙이 재미있는가, 지치는가
2. 미리 끓이기와 주문 조리 사이의 준비 판단이 의미 있게 느껴지는가
3. 정산 후 "내일은 더 잘해야지", "이걸 사고 싶다"는 욕구가 생기는가
