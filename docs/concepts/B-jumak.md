# 기획안 B: 주막 경영

최종 수정: 2026-11-05
상태: 검토 중. 초안 v0.1. 퇴마청안과 비교는 [01 게임 기획서](../01-game-design.md) 참고.

## 1. 콘셉트

### 1.1 한 줄 피치
> 조선의 길목에 있는 낡은 주막을 물려받아, 음식을 차리고 손님을 맞고, 주막을 키워 팔도에 소문난 주막으로 만든다.

### 1.2 장르
경영 시뮬레이션 (가게 운영 + 요리 + 손님 응대)

### 1.3 가제
(미정)

### 1.4 세계관
- 시대: 조선. 실존 인물과 실제 역사 사건은 직접 다루지 않는다
- 주막은 길손이 밥을 먹고 술을 마시고 하룻밤 묵어 가는 곳. 소문과 이야기가 모이는 장소
- 톤: (미정) 따뜻하고 편안한 분위기(코지)를 기본으로 검토 [확인 필요]

### 1.5 변형안: 밤 주막 (선택)
낮에는 사람 손님, 해가 지면 도깨비, 구미호, 귀신 같은 요괴 손님이 찾아오는 주막.
- 장점: 흔한 요리 경영 장르와 확실히 구별되는 훅. 한국 설화 소재를 그대로 살린다. 낮과 밤 조명 대비가 HD-2D와 잘 맞는다
- 단점: 손님 종류와 연출이 두 배로 늘어난다
- 퇴마청안의 요괴 소재를 흡수하는 절충안이기도 하다
- 채택 여부: [확인 필요]

### 1.6 핵심 경험
- 작은 초가 주막이 북적이는 큰 주막으로 커 가는 성취감
- 손님 취향을 맞춰 단골을 만드는 재미
- 하루 장사를 마치고 엽전을 세는 소소한 만족

### 1.7 레퍼런스
| 게임 | 가져올 점 | 피할 점 |
|---|---|---|
| 카이로소프트 게임 (라면가게, 온천 등) | 작은 가게를 키우는 경영, 저가 대비 긴 플레이 | 단조로운 반복 |
| Coffee Talk, Wanderer's Inn 류 | 손님 이야기가 쌓이는 정서 | 텍스트 과다 |
| Stardew Valley | 하루 단위 루프, 계절 변화, 편안한 분위기 | 범위 과다 |
| Potion Craft, Travellers Rest | 조리와 가게 운영의 결합 | 복잡한 조리 조작 |

### 1.8 타깃 플레이어
- 코지 게임과 가게 경영 게임을 좋아하는 PC 플레이어
- 한국 음식과 전통 문화에 관심 있는 국내외 플레이어
- 짧게 하루 장사만 하고 끄는 플레이 패턴

### 1.9 가격과 분량 기준
- 가격대: 2,000원 ~ 5,000원
- 주막 하나를 끝까지 키우는 데 6~10시간
- 반복 가치는 지역(시나리오) 바꿔 다시 시작하기와 수집으로 만든다

## 2. 핵심 루프

### 2.1 하루 루프 (5~10분)
1. 새벽 장보기: 장터에서 재료를 산다. 계절과 장날에 따라 값과 품목이 바뀐다
2. 영업 준비: 오늘 메뉴를 정하고, 국밥 솥을 끓이고, 술을 빚는다 (술은 숙성에 며칠이 걸린다)
3. 영업: 손님이 오면 자리로 안내하고, 주문을 받아 조리하고 차려 낸다
4. 마감 정산: 매출, 평판, 손님 이야기와 소문을 확인한다
5. 확장: 평상, 방, 부엌 설비, 마구간, 장독대를 늘리거나 꾸민다
6. 다음 날로

### 2.2 계절과 행사
- 계절별 제철 재료와 메뉴 (봄 나물, 여름 냉국, 가을 전어, 겨울 국밥)
- 장날: 손님 급증
- 과거 시험 철: 선비 손님이 몰린다
- 명절: 특별 메뉴
- 특별 손님: 신분을 숨긴 암행어사, 큰손 보부상, 소문난 미식가. 대접 결과가 평판에 크게 반영

### 2.3 장기 목표와 반복
- 주막 → 큰 주막 → 객주(숙박과 상단 거래)로 성장
- 지역 시나리오: 고갯길 주막, 나루터 주막, 장터 주막. 지역마다 손님층, 재료, 목표가 다르다
- 수집: 레시피, 단골 손님 이야기, 꾸미기 장식

## 3. 게임플레이 시스템

핵심 시스템은 3개로 제한합니다.

### 3.1 주막 공간 운영
- 목적: 공간이 성장하는 성취감
- 규칙: 부지 안에 평상, 방, 부엌, 장독대 등을 배치하고 업그레이드한다. 배치가 손님 동선과 회전율에 영향을 준다
- 우선순위: 프로토타입 필수

### 3.2 요리와 영업
- 목적: 메뉴를 짜고 손님을 빠르게 대접하는 재미
- 규칙: 레시피는 재료 조합. 장보기, 숙성, 조리 시간이 있다
- 조작 방식: (미정) 아래 중 결정 [확인 필요]
  - 직접 조작형: 주인 캐릭터를 움직여 조리하고 서빙. 손맛이 있지만 캐릭터 애니메이션 부담이 크다
  - 운영형: 일꾼을 고용해 배치하고, 플레이어는 메뉴와 배치, 확장을 결정. 아트 부담이 적고 경영 비중이 크다
  - 혼합형: 초반에는 직접 하고, 일꾼을 들이면서 점차 자동화
- 우선순위: 프로토타입 필수

### 3.3 손님과 평판
- 목적: 손님마다 다른 취향을 읽고 단골을 만드는 재미
- 손님 유형 예시: 보부상, 선비, 농부, 포졸, 나그네, 양반, 스님
- 규칙: 손님마다 선호 음식, 지불 능력, 인내심이 있다. 만족도가 평판과 소문으로 쌓인다
- 단골: 여러 번 온 손님은 개인 이야기가 열린다
- 우선순위: 프로토타입 필수

## 4. 시점과 카메라
- 쿼터뷰 디오라마. 고정 각도에 90도 단위 회전과 확대, 축소
- 새벽에서 밤까지 시간대 조명 변화. 밤에는 청사초롱과 부뚜막 불빛

## 5. 아트 부담

| 대상 | 방식 | 부담 |
|---|---|---|
| 주막 건물과 시설 | 블록과 소품 조립 | 중간. 가장 강한 영역 |
| 음식과 재료 아이콘 | 작은 픽셀 소품 | 낮음. 강한 영역 |
| 손님 | 부위 조합 + 걷기, 앉기, 먹기 동작 | 높음. 동작이 퇴마청보다 많다 |
| 주인과 일꾼 | 조리, 운반 동작 (직접 조작형이면 더 많음) | 중간 ~ 높음 |
| 시간대와 계절 | 조명과 후처리 | 낮음 |

## 6. 범위 관리

| 구분 | 내용 |
|---|---|
| 반드시 있어야 하는 것 | 하루 루프 전체, 시설 10종 이상, 레시피 20종 이상, 손님 유형 6종 이상, 지역 1곳 |
| 있으면 좋은 것 | 지역 2~3곳, 밤 주막 변형, 단골 이야기, 꾸미기 장식 |
| 이번 버전에서 제외 | 넓은 마을 탐험, 연애 요소, 음성 연기, 멀티플레이 |
