# 기획안 A: 퇴마청

최종 수정: 2026-11-05
상태: 보류 (킵). 초안 v0.1. 주막 경영안과 비교 후 결정합니다. 비교는 [01 게임 기획서](../01-game-design.md) 참고.

## 1. 콘셉트

### 1.1 한 줄 피치
> 조선의 한 고을, 다 쓰러져 가는 마물 퇴치 관청에 새로 부임한 수령이 되어 퇴마사를 모으고, 민원을 결재하고, 관아를 키워 고을을 요괴로부터 지킨다.

### 1.2 장르
경영 시뮬레이션 (거점 운영 + 인원 파견)

### 1.3 가제
퇴마청 (退魔廳). 마물을 물리치는 관청. 검토했던 다른 후보는 벽사청, 제마사.

### 1.4 세계관
- 시대: 조선. 실존 관청 체계(포도청, 관상감 등)를 본뜬 가상의 관청이 있다는 설정의 역사 판타지
- 요괴가 실제로 존재하고, 고을마다 마물 퇴치를 맡은 관청이 있다
- 플레이어의 관청은 오래 방치되어 건물은 낡고 인원은 거의 없다
- 실존 인물과 실제 역사 사건은 직접 다루지 않는다
- 톤: (미정) 진지한 퇴마물과 유쾌한 관청 생활 사이에서 결정 [확인 필요]

### 1.5 핵심 경험
- 낡은 관아가 내 손으로 번듯한 관청으로 커 가는 성취감
- 사건마다 맞는 퇴마사를 골라 보내는 판단의 재미
- 결재 도장을 찍고, 보고서를 받아 보는 조선 관청 업무의 맛

### 1.6 레퍼런스
| 게임 | 가져올 점 | 피할 점 |
|---|---|---|
| Darkest Dungeon | 거점 운영, 인원의 부상과 피로, 고유 성격 | 무거운 난이도, 긴 던전 전투 |
| This Is the Police | 사건 접수와 인원 배치의 긴장감 | 지나치게 많은 동시 사건 |
| Two Point Hospital, 카이로소프트 게임 | 작은 공간을 키우는 경영, 시설 배치 | 수치만 보는 운영 |
| Papers, Please | 서류 결재 연출, 판단의 무게 | 반복 작업의 피로 |

### 1.7 타깃 플레이어
- 경영 시뮬과 수집, 성장 요소를 좋아하는 PC 플레이어
- 한국 설화와 사극 분위기에 관심 있는 국내외 플레이어
- 한 번에 30분~1시간씩 끊어서 하는 플레이 패턴

### 1.8 가격과 분량 기준
- 가격대: 2,000원 ~ 5,000원 (분량상 상한에 가깝게 예상)
- 임기 1회 2~3시간, 여러 임기를 반복해 총 10시간 이상
- 반복 플레이 가치로 가격을 정당화한다

## 2. 핵심 루프 (Core Loop)

### 2.1 하루 루프 (5~10분)
1. 아침 조회: 민원과 사건 의뢰서가 들어온다
2. 결재: 사건을 검토하고 맡을 사건을 고른다. 도장을 찍어 승인
3. 파견: 사건마다 퇴마사를 배치한다. 요괴 속성과 퇴마사 특기의 상성을 고려
4. 관아 운영: 파견 중에 시설을 짓고, 남은 인원을 훈련시키고, 부상자를 치료한다
5. 저녁 보고: 결과 보고서가 도착한다. 엽전, 요괴 재료, 명성을 얻거나 잃는다
6. 다음 날로

### 2.2 계절 루프 (한 계절 = 여러 날)
- 계절마다 출몰하는 요괴가 바뀐다 (봄 꽃귀신, 여름 물귀신, 가을 도깨비, 겨울 설귀 등. 목록은 미정)
- 계절 끝에 관찰사 감찰: 실적 평가, 예산 증감
- 큰 요괴 사건 (보스): 구미호, 불가사리, 이무기 등. 여러 퇴마사를 묶어 대응

### 2.3 임기 루프 (한 판 = 임기, 2~3시간)
- 수령의 임기(예: 3년, 12계절)가 끝나면 최종 고과를 받는다
- 고과 결과에 따라 다음 부임지와 해금 요소가 정해진다
- 새 임지에서 새 관청을 다시 키운다. 임지마다 지형, 요괴, 민원 성향이 다르다
- 반복 장치: 무작위 사건과 무작위 인재, 임지 변화, 해금

## 3. 게임플레이 시스템

핵심 시스템은 3개로 제한합니다.

### 3.1 관아 운영
- 목적: 공간이 성장하는 성취감. HD-2D 디오라마를 가장 많이 보여 주는 시스템
- 규칙: 정해진 부지 안에 건물과 시설을 짓고 업그레이드한다. 부지는 단계적으로 넓어진다
- 시설 예시: 동헌(집무), 숙소, 훈련장, 무기고, 약방, 사당, 옥사(요괴 봉인), 장독대와 부엌(사기 회복)
- 자원: 엽전(예산), 요괴 재료(특수 시설과 장비), 명성(해금 조건)
- 우선순위: 프로토타입 필수

### 3.2 퇴마사 관리
- 목적: 애착 가는 인원을 키우는 재미
- 규칙: 무작위로 나타나는 인재를 모집한다. 각자 직업, 능력치, 특기, 성격이 있다
- 직업 예시: 무관(물리), 무녀(귀신), 승려(봉인), 포졸(수색), 의원(치료), 도사(부적)
- 상태: 피로, 부상, 사기. 무리하게 보내면 실패 확률이 오르고 다칠 수 있다
- 성장: 사건 경험으로 레벨업, 훈련장으로 능력 향상, 장비 착용
- 우선순위: 프로토타입 필수

### 3.3 사건 파견
- 목적: 상성을 읽고 사람을 고르는 판단의 재미
- 규칙: 사건 의뢰서에 요괴 단서(목격담, 피해 양상)가 적혀 있다. 단서로 요괴를 추리해 맞는 퇴마사를 보낸다
- 판정: 퇴마사 능력과 상성, 상태로 성공률을 계산해 자동 진행
- 결과: 보고서 두루마리와 짧은 장면 연출로 보여 준다
- 보스 사건: 여러 명을 묶어 보내고, 진행 중 1~2회 선택지(부적 사용, 후퇴 등)를 고른다
- 직접 전투: (미정) 자동 판정만 둘지, 보스만 간단한 지휘 화면을 둘지 결정 [확인 필요]
- 우선순위: 프로토타입 필수

## 4. 진행 구조

| 단위 | 길이 | 내용 |
|---|---|---|
| 하루 | 5~10분 | 결재, 파견, 운영, 보고 |
| 계절 | 여러 날 | 출몰 요괴 변화, 감찰, 보스 사건 |
| 임기 | 2~3시간 | 한 판. 최종 고과와 다음 임지 |
| 전체 | 10시간 이상 | 임지 2~3곳, 해금 요소 |

## 5. 조작

| 동작 | 키보드/마우스 | 게임패드 |
|---|---|---|
| 선택, 결재 | 왼쪽 클릭 | A |
| 카메라 이동 | 드래그 또는 WASD | 왼쪽 스틱 |
| 카메라 회전 | Q / E | 숄더 버튼 |
| 확대, 축소 | 휠 | 트리거 |
| 메뉴 | Esc | 시작 버튼 |

마우스 중심 게임이지만 Steam 출시 기준으로 게임패드도 지원합니다. macOS에서는 Command 키 등 키 배치 차이를 고려합니다.

## 6. 시점과 카메라

- 관아 화면: 쿼터뷰 디오라마. 고정 각도에 90도 단위 회전과 확대, 축소만 허용
- 틸트 시프트와 시간대 조명으로 미니어처 같은 관아를 보여 준다
- 사건 연출: 보고서 두루마리 + 요괴가 등장하는 짧은 HD-2D 장면

## 7. 아트 방향

- 스타일: 한국형 HD-2D (픽셀 스프라이트, 3D 공간, 실시간 조명, 피사계 심도, 블룸)
- 테마: 조선 관아 건축, 한복, 한국 설화 요괴. 상세 소재 목록은 [07 아트 파이프라인 1.1](../07-art-pipeline.md)
- 기법 참고: Octopath Traveler, Triangle Strategy, Sea of Stars의 조명 연출
- 제작 방식: Claude가 코드로 생성. 상세는 [07 아트 파이프라인](../07-art-pipeline.md)

이 콘셉트에서 아트 부담이 어떻게 나뉘는지:

| 대상 | 방식 | 부담 |
|---|---|---|
| 관아 건물과 시설 | 블록과 소품 조립 | 중간. 가장 강한 영역 |
| 시간대와 계절 | 조명과 후처리, 계절별 텍스처 변형 | 낮음 |
| 퇴마사 | 부위 조합 (얼굴, 머리, 갓, 의복 색) + 걷기, 대기 동작 | 중간 |
| 요괴 | 정지 스프라이트 + 흔들림, 번쩍임, 파티클 | 중간 |
| 서류, 도장, 두루마리 UI | 한지 질감, 먹 글씨, 낙관 | 낮음 |

## 8. 사운드와 음악

> (미정) 국악 악기(가야금, 대금, 해금, 장구)를 쓴 배경 음악 방향 검토. 1인 개발이므로 음원 조달 방식 결정 필요

## 9. UI / UX

- 한지 서류와 두루마리, 먹 글씨, 붉은 낙관을 UI의 기본 언어로 쓴다
- 결재는 도장을 찍는 연출로 처리해 반복 동작에 손맛을 준다
- 메인 메뉴, 설정(그래픽, 오디오, 키 설정, 언어), 일시정지 화면은 공통 필수
- 해상도와 창 모드 설정은 Windows와 macOS 모두에서 검증

## 10. 현지화

- 기본 언어: 한국어
- 추가 언어: 영어 (해외 판매 고려). 관직명과 요괴 이름의 번역 원칙을 정해야 한다
- 텍스트 분량이 많은 장르이므로 처음부터 언리얼 현지화 시스템으로 문자열을 관리한다

## 11. 범위 관리

| 구분 | 내용 |
|---|---|
| 반드시 있어야 하는 것 | 하루 루프 전체, 시설 10종 이상, 퇴마사 직업 4종 이상, 요괴 20종 이상, 임지 1곳, 보스 사건 3건 |
| 있으면 좋은 것 | 임지 2~3곳, 계절별 특수 사건, 퇴마사 개인 이야기, 관아 꾸미기 장식 |
| 이번 버전에서 제외 | 직접 조작 전투, 넓은 필드 탐험, 음성 연기, 멀티플레이 |

### 출시 기준 콘텐츠 규모 (초안)
